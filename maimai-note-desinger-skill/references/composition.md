# 从配置到谱面

配置库记录术语含义与用户资料；节奏、速度、密度、手法和段落用途仍需结合目标设计。

1. 确定作用：主旋律、鼓点、过门、情绪抬升或休息。若未提供音频，只能设计节奏草案，不能推断真实乐曲的重音。
2. 确定范围、BPM、拍号语义、目标难度与主要配置；用户允许自由发挥时选择短而完整的段落。
3. 展开逐击时间与键位，注明预期 L/R 用手。匀拍交互逐击换手，纵连需检查重复键位上的时序和定位；单靠键位左右分区不能决定用手。
4. 检查双押、HOLD、SLIDE 占用是否超过预期手数；跨区移动、反手、出张和连续扫键留出可执行的时间。不要把手法名称自动视为“更难更好”。
5. 对照前后段落的密度、移动方向和休息点；难度判断同时考虑 BPM、最短间隔、视认与身体动作。
6. 生成可审核提案，说明音符数、范围、采用配置与尚待人工确认的手法。

参考 Simai 应按任务局部读取。先辨认 BPM、分拍、音型与手法，再迁移到目标曲的节奏和段落；不要机械复制原曲键位与时长。保留参考来源，区分用户原例、整理者解释和生成草案。

“连续的双压”目前只有名称，原稿定义缺失；“大宇宙”保留了两处来源的描述。遇到缺定义或术语歧义，可生成明确描述的基础音型，但不要冒称该条目的标准范例。
