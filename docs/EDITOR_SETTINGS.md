# 编辑器设置与判定区间

## 入口

- 顶栏“文件 / 编辑 / 视图 / 播放 / 设置 / 帮助”提供对应下拉操作。
- `F1` 或 `Cmd/Ctrl+,` 打开设置，`Esc` 关闭。“设置 → 所有设置”也可打开。
- “视图 → 显示判定区间”或设置里的“视图与判定 → 显示判定区间”控制同一个开关，默认关闭。
- 设置窗口按视图、编辑器、Note 尺寸、Slide、Touch、Pad、音效、流速与播放、背景视频分类，修改即时生效。
- “保存设置”保存渲染与默认播放参数，下次启动继续使用；布局、侧栏、细分、吸附、滚轮方向与预览模式仍是本次编辑会话状态。
- 下拉菜单和设置窗口打开时，画布不会同时处理放置、拖动或播放快捷键。

## 缩放与 Autoplay

- 谱面与 Autoplay 的时间轴统一支持 10–4800 px/s，数值越小显示的时间范围越远，数值越大则放大时间细节。
- 默认 360 px/s，是原先 120 px/s 的 3 倍放大；不改变音符贴图尺寸。切换两个工作区时保留倍率。
- “流速与播放 → Autoplay 内屏模式”与 Autoplay 属性区的内屏开关同步，默认开启：核心生成的 K1–K8 点击、按下、松开转换为对应的 A1–A8。
- 关闭内屏模式后保留核心按钮事件；显示、模拟触摸、直传核心和 seek 使用一致的配置。手工编辑的事件组与外部回放保留原来的区域，不自动改写。
- 切换内屏模式仅在当前核心会话中恢复当前时间及按住状态，不重建核心，不重启音乐；通过“保存设置”可保留到下次启动。

## 显示内容

- 颜色由外到内为蓝色 Good、粉色 Great、黄色 Perfect、浅黄色 Critical Perfect；白线表示判定基准时刻。
- Tap、Touch、非无头星星及 Hold 头部显示点击时间窗口。EX 环形头部的有效命中都提升为 Critical Perfect；Touch 保留自己的非对称窗口。
- Timeline 在音符所在轨道按时间绘制；Pad 的环形音符按飞行速度映射到判定圈附近，Touch 用感应区上的时间弧表示。
- 普通 Hold / TouchHold 额外显示绿色有效保持距离及最早可松手刻度。以准时按下、持续按住为前提，按核心有效时长的 67% 门槛保留 Perfect；不是完整贴图长度，也不是最终判定的保证。
- 过短 Hold 没有独立保持要求；经典 Hold 显示尾部 Perfect 释放窗口，尾部只能保留或降低头部等级，不会提升等级。
- Slide 每条完整子轨迹只有一个末端窗口，连续 Slide 的中间连接段不重复显示；同头多轨迹分别显示。Timeline 放在结束 lane，Pad 沿实际星星轨迹绘制，WiFi 对应三条路径。
- Slide 末端显示 Great / Perfect 时间窗口。须先按顺序完成此前感应区，星星到达区间不代表无需完成轨迹就能获得该等级。末端时间弧表示到达终点之后仍有效的延迟窗口。
- Slide Good 没有固定的早侧窗口，不能画成以终点对称的有限区间，因此不绘制虚构的 Good 范围。核心默认将 Slide 的 Perfect 子等级合并为 Critical Perfect。

## 数据与限制

- 阈值依据 `LnmaiCore/Judge.lean`、`Constants.lean` 与 `Lifecycle.lean`；Slide 的判定基准、停留时间、连续轨迹终点及经典模式来自已加载核心的 ChartSpec。
- 这些是只读诊断覆盖层，不改变判定、评分、吸附或音符时值；更改谱面并同步核心后会刷新对应元数据，不在每帧重建核心。
- 运行时 NoCore 仍可使用已加载的核心元数据；编译为 `backend-none` 或核心载入失败时没有 Slide 的精确末端元数据，不会猜测绘制。

## 验证

- 判定规则测试覆盖 Touch 非对称窗口、短 Hold、67% 保持要求、经典 Hold 严格边界、Slide 动态窗口、连续轨迹末端与稳定编辑 ID，以及路径按弧长裁剪。
- 设置测试覆盖旧 JSON 的默认关闭值、开启状态保存还原，以及 F1 不改变宿主 DPI。
- 原生窗口截图通过 `MAI2_EDITOR_JUDGE_WINDOWS=1`、`MAI2_EDITOR_SHOW_SETTINGS=1`、`MAI2_EDITOR_TIME` 与 `MAI2_EDITOR_WINDOW=宽x高` 复核，不写回偏好设置。
