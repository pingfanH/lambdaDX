# 编辑器设置与判定区间

## 入口

- 顶栏“文件 / 编辑 / 视图 / 播放 / 设置 / 帮助”提供对应下拉操作。
- `F1` 或 `Cmd/Ctrl+,` 打开设置，`Esc` 关闭。“设置 → 所有设置”也可打开。
- “编辑与导航 → Slide 放置后默认直线到对面”控制新 Slide 是否默认建立对面直线路径, 默认关闭。鼠标放置开启此项时会立即提交对面直线路径并进入可继续调整的编辑; 关闭时需先补全路径再确认, Esc 会取消未确认草稿。键盘放置会把对面作为默认终点, 仍需 Enter 确认键盘事务。
- “视图 → 显示判定区间”或设置里的“视图与判定 → 显示判定区间”控制同一个开关，默认关闭。
- 设置窗口按视图、编辑器、Note 尺寸、Slide、Touch、Pad、音效、流速与播放、背景视频分类，修改即时生效。
- “保存设置”保存全局渲染与默认播放参数；“视图 → 布局”中的保存操作另外保存当前工作区的布局和各分区视图设置。
- Pad 标题栏菜单中的“隐藏 Notes”“隐藏感应区”“显示判定区间”修改后自动保存为全局显示设置；保存失败时在顶栏显示错误。
- Pad 的 NoCore、手动判定、模拟触摸、直传核心模式自动保存到用户缓存中的 editor_workspaces.json，重启后恢复并应用到播放器；播放模式由所有工作区共享，不随分区切换而重置。
- 下拉菜单和设置窗口打开时，画布不会同时处理放置、拖动或播放快捷键。

## 文件选择

- macOS 的打开谱面、另存为、导出和背景图选择共用原生异步面板，附着在编辑器窗口上，打开时直接获得焦点。选择期间暂停画布输入，确认或取消后恢复。
- 打开谱面、保存/导出、背景图片分别记住上次确认选择的目录，保存在 `output/editor_file_dialogs.json`，重启后仍然生效。取消不会覆盖记录。
- 上次目录不存在时，优先使用当前谱面或背景图的目录，再退回用户目录；不会传入空目录。
- 面板在启动阶段预热并在后续选择中复用，不再每次启动外部脚本进程。macOS 首次初始化文件浏览服务仍有成本；目录验证、记录读写和等待选择结果不阻塞渲染线程。

## 外观与背景

- 设置中的“编辑器 → 外观与背景”提供透明界面开关和 0–100% 界面不透明度，默认 68%。
- 默认背景为 `assets/editor_background.jpg`，图片亮度单独调节，默认 55%。图片按比例居中铺满窗口，超出部分裁切。
- 可以开关背景、输入图片路径、恢复默认图片；macOS 还提供 PNG/JPEG 文件选择器。相对路径以 `assets` 目录为基准。
- “背景水印”默认开启，文字为 `禁止泄漏! Don't Leak`，以白色、18% 不透明度、32 字号、-25° 交错平铺。旧版外观配置升级后同样默认开启。
- 水印编辑支持文字、颜色、不透明度、字号、角度与横纵间距，重置按钮恢复默认水印；关闭水印或清空文字可隐藏。关闭背景图片或图片加载失败时，水印仍绘制在纯色背景上。
- 水印属于编辑器背景，位于 Note、击打特效及操作控件下方；Pad 圆外遮罩沿用同一背景，不擦除或错位水印。水印设置随外观自动保存，不写入谱面或 Simai。
- 面板底色可透明，文字、note、选中标记和手柄不随之变淡；菜单与设置浮层保持至少 90% 不透明度。Pad 移除黑色底盘和圆外黑色遮罩，直接透出编辑器背景，保留圆形裁切、感应区与判定效果。
- 打开或重新加载谱面时，后台读取谱面同目录的封面，优先级为 `bg.jpg`、`bg.png`、`bg.jpeg`、`cover.jpg`、`cover.png`、`jacket.jpg`、`jacket.png`、`cover.jpeg`、`jacket.jpeg`。封面按比例居中裁切到 Pad 内；没有封面时保持透明，切换谱面不会沿用上一首封面。
- 外观即时预览并独立自动保存到 `output/editor_appearance.json`，不需要点击“保存设置”，不写入谱面。失败时保留当前效果并显示重试入口。
- 图片后台加载并缓存，调亮度与透明度不重复读取图片；当前不包含实时磨砂或桌面窗口穿透效果。
- “操作时淡化其他分区”默认关闭。放置、移动或编辑 note/Autoplay 草稿时，其他操作仍被禁用，但默认不额外变暗；开启后显示淡化反馈。该选项随外观设置自动保存。

## 分区与整曲导航

- 谱面分区分别保留横向/纵向、倍率、视图位置、吸附与细分、播放线跟随、光标跟随、滚轮方向；Autoplay 分区分别保留倍率、视图位置、吸附与细分、跟随、轨道数量、原始事件显示与筛选。Pad 的预览倍率、“仅预览”与内容来源、Simai 的显示与跟随选项也随分区保留。
- 切换“谱面 / Autoplay / 组合 / Simai”工作区不会用另一个工作区的分区设置覆盖当前设置；移动或交换分区时设置跟着分区走。现有布局规则仍是一个工作区内每种编辑器最多一个分区。
- 保存当前工作区布局后，这些设置重启仍可恢复；恢复布局会恢复已保存的视图设置，重置布局则使用默认设置。旧版布局文件仍可读取。谱面内容、播放时间、循环范围及全局渲染参数不属于分区独立设置。
- 谱面时间轴两侧新增整曲进度条：纵向布局在左右，横向布局在上下。进度条始终表示整首时间线，不受当前倍率影响；浅色范围表示当前视图，红线表示播放位置，黄色表示循环范围。
- 点击或拖动任一侧可定位并带动视图，拖出边缘会限制到整曲首尾，松开即结束定位，不会同时放置 note。

## 缩放与 Autoplay

- 谱面与 Autoplay 的时间轴统一支持 10–4800 px/s，数值越小显示的时间范围越远，数值越大则放大时间细节。
- 默认 360 px/s，是原先 120 px/s 的 3 倍放大；不改变音符贴图尺寸。切换两个工作区时保留倍率。
- “流速与播放 → Autoplay 内屏模式”与 Autoplay 属性区的内屏开关同步，默认开启：核心生成的 K1–K8 点击、按下、松开转换为对应的 A1–A8。
- 关闭内屏模式后保留核心按钮事件；显示、模拟触摸、直传核心和 seek 使用一致的配置。手工编辑的事件组与外部回放保留原来的区域，不自动改写。
- 切换内屏模式仅在当前核心会话中恢复当前时间及按住状态，不重建核心，不重启音乐；通过“保存设置”可保留到下次启动。
- Autoplay 的曲线编辑在属性区使用“Map Slide / Edit curve”，或用钢笔按钮在 Pad 上新建；支持恒速和固定总时长，确认后转换为 sensor 事件。具体操作及 Wi-Fi 限制见 [Autoplay 操作文档](EDITOR_AUTOPLAY.md#pad-curves)。保存为原生 JSON 才会保留曲线与自定义事件，Simai 导出不包含它们。

## 显示内容

- 颜色由外到内为蓝色 Good、粉色 Great、黄色 Perfect、浅黄色 Critical Perfect；白线表示判定基准时刻。
- Tap、Touch、非无头星星及 Hold 头部显示点击时间窗口。EX 环形头部的有效命中都提升为 Critical Perfect；Touch 保留自己的非对称窗口。
- Timeline 在音符所在轨道按时间绘制；Pad 的环形音符按飞行速度映射到判定圈附近，Touch 用感应区上的时间弧表示。
- 普通 Hold / TouchHold 额外显示绿色有效保持距离及最早可松手刻度。以准时按下、持续按住为前提，按核心有效时长的 67% 门槛保留 Perfect；不是完整贴图长度，也不是最终判定的保证。
- 过短 Hold 没有独立保持要求；经典 Hold 显示尾部 Perfect 释放窗口，尾部只能保留或降低头部等级，不会提升等级。
- Slide 每条完整子轨迹只有一个末端窗口，连续 Slide 的中间连接段不重复显示；同头多轨迹分别显示。Timeline 放在结束 lane，Pad 沿实际星星轨迹绘制，WiFi 对应三条路径。
- Slide 末端显示 Great / Perfect 时间窗口。须先按顺序完成此前感应区，星星到达区间不代表无需完成轨迹就能获得该等级。末端时间弧表示到达终点之后仍有效的延迟窗口。
- Slide Good 没有固定的早侧窗口，不能画成以终点对称的有限区间，因此不绘制虚构的 Good 范围。核心默认将 Slide 的 Perfect 子等级合并为 Critical Perfect。

## 数据与限制

- 阈值依据 `LnmaiCore/Judge.lean`、`Constants.lean` 与 `Lifecycle.lean`；Slide 的判定基准、停留时间、连续轨迹终点及经典模式来自已加载核心的 ChartSpec。
- 这些是只读诊断覆盖层，不改变判定、评分、吸附或音符时值；更改谱面并同步核心后会刷新对应元数据，不在每帧重建核心。
- 运行时 NoCore 仍可使用已加载的核心元数据；编译为 `backend-none` 或核心载入失败时没有 Slide 的精确末端元数据，不会猜测绘制。

## 验证

- 判定规则测试覆盖 Touch 非对称窗口、短 Hold、67% 保持要求、经典 Hold 严格边界、Slide 动态窗口、连续轨迹末端与稳定编辑 ID，以及路径按弧长裁剪。
- 设置测试覆盖旧 JSON 的默认关闭值、开启状态保存还原，以及 F1 不改变宿主 DPI。
- 水印测试覆盖旧外观配置默认值、参数边界、旋转平铺间距、设置开关与自动保存后的重启恢复。
- 原生窗口截图通过 `MAI2_EDITOR_JUDGE_WINDOWS=1`、`MAI2_EDITOR_SHOW_SETTINGS=1`、`MAI2_EDITOR_TIME` 与 `MAI2_EDITOR_WINDOW=宽x高` 复核，不写回偏好设置。
