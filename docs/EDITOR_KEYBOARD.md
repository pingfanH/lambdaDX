# Editor 当前键盘操作

更新: 2026-10-16。Primary 在 macOS 是 Command, 在 Windows/Linux 是 Ctrl; Alt 在 macOS 是 Option。
这是当前接入版本的操作说明, 完整目标另见 [键盘方案](EDITOR_KEYBOARD_PLAN.md)。

## 播放与输入归属

| 按键 | 操作 |
| --- | --- |
| Space | 播放 / 暂停 |
| Alt+Space | 从头开始播放 |
| Alt+Enter | 跳转到谱面编辑光标或 Simai 文本光标对应拍点, 保留播放或暂停状态 |
| Alt+Shift+Enter | 切换时间轴跟随当前分区的编辑光标, 默认关闭; 开启时立即对齐一次 |
| Alt+Home | 回到开头; 循环开启且正在播放时回循环起点, 其他情况回歌曲开头 |
| Alt+Left / Right | 后退 / 前进 1 秒 |
| Alt+Up / Down | 播放速度增加 / 减少 0.1 |
| A | 音乐开关 |
| O / P | 切换自动打歌 / 循环预览模式 |
| F1 / Primary+, | 设置 |
| F6 / Shift+F6 | 按屏幕顺序切到下一个 / 上一个可见区域 |
| F12 / ? | 快捷键帮助 |

Space 在画布空闲时生效; Simai 文本框默认也用 Space 播放/暂停, 不输入空格, 可在 Simai 设置中关闭。其他输入框、输入法组合、下拉菜单、对话框及未确认的放置/变换拥有输入时, 不执行播放快捷键。
先按 Enter 确认或 Esc 取消当前操作; 设置与帮助按 Esc 关闭, 然后按 Space。长按 Space 不会反复切换播放。
也可使用顶栏“播放 → 播放/暂停”。菜单仅拦截画布输入, 不临时隐藏时间轴或改变工具栏颜色。
鼠标悬停不抢焦点; 点击区域或 F6 切换。放置、变换与拖拽期间先确认或取消, 再切区域。
属性、Pad 等辅助区域不会把字母快捷键误发给另一时间轴。

## 光标、选择与工具

- F4 打开工具列表, Up/Down 选择, Enter 确认, Esc 取消。切换工具不清除 note 选择。
- 竖向时间轴: Up/Down 推后/提前时间, Left/Right 切 lane。横向: Right/Left 推后/提前时间, Down/Up 切 lane。
- 方向键或 Primary+方向键均可导航; 时间方向一次移动当前细分的一格, lane 方向一次移动一个 lane。加 Shift 后分别移动一个小节、四个 lane。支持长按, 同时按住时间与 lane 方向可连续斜向移动。
- 1..8 设置 lane。键盘导航默认只移动编辑光标, 不改变播放位置或播放/暂停状态; 光标在可见范围内移动时视图不动, 超出边界才继续滚动。编辑光标可移到歌曲末尾以外以继续放置。Alt+Shift+Enter 或设置 > 编辑与导航中的“时间轴跟随谱面光标”可切换联动, 谱面标题的视图菜单也有同一开关; Alt+Enter 可随时将播放位置跳到光标。放置草稿、变换与 Slide 分段编辑保留各自的方向键含义。
- Simai 输入框同样支持 Alt+Enter 和 Alt+Shift+Enter, 操作的是文本输入光标对应拍点, 使用独立的“时间轴跟随文本光标”开关。跟随只在光标改变时定位, 不会因为光标停留而反复 seek; 文本未应用或映射未就绪时等待最新有效映射。
- J 打开定位框, 输入小节小数 (如 `2.5`) 或秒数 (如 `3s`), Enter 同时定位编辑光标、播放时钟和时间轴视图, 保留播放/暂停状态; 超出歌曲末尾时三者一起限制到末尾。
- Home/End 移动编辑光标到谱面起点/末尾; PageUp/PageDown 按页面移动。F8 切吸附, [ / ] 切细分。
- Tab/Shift+Tab 按时间跳到下一个/上一个 note, 同时值按 lane、稳定 ID 排序, 到头后循环; 支持按住连续切换, 默认不改变播放位置, 仅在目标超出可见边界时滚动视图, 不自动选择。鼠标点击 note 会将其设为新的 Tab 参考, 点击空白则以点击位置为参考, 点击本身不因此触发 seek。光标位于两个 note 之间时从当前位置向前/后查找。F2 选择候选, Shift+F2 添加或移除候选。Primary+A 全选, Primary+Shift+A 清选择。
- 键盘光标指到 note 后, 右侧属性和 F5 直接显示该 note; Delete/Backspace/D 直接删除它, 无需先选中, 不影响其他选择。光标指向空白时不误删其他选择; 鼠标操作仍使用选择集合。
- Primary+Enter 设置范围锚点, 方向键、1..8 或 Tab 移动另一角, Enter 或再次 Primary+Enter 确认范围选择。Primary+Shift+Enter 开始或 Shift+Enter 确认可追加范围; Esc 取消并保留原选择。范围可跨屏, 越界时视图继续滚动; 框选时不会放置 note, 也不会切换工具或启动播放。
- Primary+Delete/Backspace 删除整个选择集合; 普通 Delete/Backspace/D 仍只删除光标指向的 note。选中的一组可直接使用 G/S/R、Shift+D 或 Primary+C/X 操作。
- 在空闲画布显式点击鼠标可回到鼠标操作; 未确认键盘事务不会被鼠标移动接管。

## 放置

1. F4 选工具, 方向键与 1..8 定位。也可用 T/H/C 等单键切工具, 但选中 note 时 G/S 优先用于变换。
2. Tap/Touch: Enter 放置。Hold/TouchHold: Enter 固定头部, 时间方向键设置尾端, Enter 完成; Esc 取消。
3. Star: Enter 固定头部, 时间方向键设置启动拍, Enter 进入轨迹阶段; 1..8 设置结束 lane, 时间方向键设置结束拍, Enter 完成。
4. Star 轨迹阶段默认直线; Q/P/S/Z/V/W 或 - / , / . / ; 选择形状。Shift+Q/P 为 QQ/PP。Shift+Enter 确认并继续下一连接段。

Hold 尾端可为零长度。Star 非法端点或早于启动拍的尾端不会提交, 可继续调整。Star 放置的 Esc 逐步返回, 再次 Esc 取消整条草稿。
一次完整 Hold/Star 放置只产生一次撤销; 确认事件不会额外放置另一个 note。

## 编辑与历史

Simai 文本分区可选择标准、Vim、Helix 模式，并支持上下文补全、括号配对和片段字段。
完整首版键位与边界见 [Simai 模态编辑与代码补全](EDITOR_SIMAI_EDITING.md)。
Vim/Helix 的 Insert 模式下 Space 输入空格，不触发播放；Normal 模式保留播放开关。
Ctrl+Space 打开补全，Up/Down 选择，Tab/Enter 接受，Esc 先关闭候选或片段再退出模式。
块状光标、滚动跟随与 Alt+Enter 使用相同的当前字符位置；上下移动经过短行后仍恢复原列。
支持 `iw/aw` 单词对象、`2gg/3G` 行号跳转、`?` 反向搜索及 `n/N` 重复搜索，匹配以黄色背景标出。

- 选中单个 Star 后 E 进入/退出轨迹编辑; Tab 切同头子 slide, Primary+Left/Right 切连接段。
- 键盘轨迹修改使用形状键与 lane 键, Enter 提交, Esc 取消草稿。Primary+Shift+D 新建同头轨迹。
- 鼠标轨迹编辑保留原逻辑: 形状键后按 lane 立即修改路径。
- F7 打开光标指向的 Hold/Star (鼠标模式下为单个所选 note) 的手柄菜单, 方向键选项目、Enter 进入调整; 方向键调整, Enter 确认, Esc 取消。
- F5 打开光标指向的 note (鼠标模式下为单个所选 note) 的时间、Break、EX 草稿, Apply/Enter 提交, Esc 取消。
- G/S/R 进入移动/时间缩放/旋转。键盘操作后可用方向键调整、直接输入数值、Enter 确认、Esc 取消; 鼠标与滚轮操作仍保留。
- Shift+D 复制并进入移动, 确认点击不会触发普通放置。Shift+R 重复上次已确认变换/复制, 或以最近两次兼容放置的时间/lane 差继续放置。删除会从参考记录中移除已删除 note, 重新使用剩下最新两次放置; 不足两个、零位移或属性不兼容时不重复。撤销、重做及其他修改仍打断放置参考。
- Primary+C/X/V 复制/剪切/粘贴, 键盘粘贴锚定编辑光标。Primary+Z 撤销, Primary+Shift+Z 或 Primary+Y 重做。Delete/Backspace/D 在键盘光标模式删除指向 note, 在鼠标模式删除选择。
- Primary+S 保存到实际打开的文件和难度; Primary+Shift+S 另存为 `.txt` / `.json`; Primary+Shift+E 导出 Simai; Primary+O 打开文件或谱面文件夹。顶栏“文件”提供相同操作与重新载入、退出。无源文件时保存会先要求另存为, 失败或取消保留未保存状态。详见 [文件操作](EDITOR_FILES.md)。
- F3 支持中英文关键词搜索: 工具、属性、手柄、定位、打开/保存/另存/导出、适配所选、
  适配全曲、回到当前、跟随、循环选中/清除循环、设置、历史、最大化、保存/恢复/重置布局。
  输入关键字, Up/Down 选择后 Enter 执行; 命令作用于当前工作区。
- “视图 > 历史”打开真实撤销列表, 点击位置跳转; 布局操作不占用谱面撤销。
- 属性顶部的固定图标锁定单个 note, 删除后显示失效状态; 取消固定恢复跟随候选/选择。
- 谱面标题的“谱面视图”菜单和设置 > 工作区与分区提供“隐藏左侧工具栏”; 隐藏后工具快捷键仍可用, 原位置不拦截鼠标。此选项随工作区视图自动保存, 重启恢复。
- 分区的类型、位置、比例与视图配置会自动保存, 退出前也会写盘。“保存当前工作区布局”保存独立快照, “恢复已保存布局”返回该快照, 不影响谱面文件或撤销记录。

## 浏览与循环

- 谱面标题的“谱面视图”菜单和设置 > 工作区与分区提供独立的“Note 大小”; 只调整当前谱面分区, 不改变 Pad 或其他工作区。重置按钮恢复跟随全局默认值, 此配置随布局自动保存。
- 开启谱面跟随时, 缩放或平移使播放线移出视图后, 恢复播放会回到可见的跟随位置; 横向高倍率按分区宽度限制跟随位置。暂停浏览及正在进行的拖动不会被强制打断, 手动关闭跟随时也不自动归位。
- 谱面与 Autoplay 都支持按住中键后偏离按下点持续滚动, 离原点越远速度越快; 回到原点
  停止, 松开结束。纵向谱面用上下方向, 横向谱面与 Autoplay 用左右方向。中键轻点 Slide 仍进入编辑。
- 两者都支持 Shift+滚轮平移时间, 不会自动关闭跟随。Autoplay 中键与平移只移动视图,
  普通滚轮滚动轨道; 谱面开启跟随时中键和滚轮同时移动播放位置, 关闭时只移动视图。
  Primary+滚轮或捏合都以鼠标下的时间点为中心缩放, 不改变播放时间。
- Autoplay 跟随开启时, 暂停仍可自由浏览; 播放线在左半屏时视图不动, 到中线才用
  约 200ms 平滑接管滚动。活动手势优先, 松开后重新按中线规则跟随; 暂停立即停止过渡。
  谱面跟随在暂停和播放时都有效, 移动时间轴后视图同步更新; 键盘光标独立浏览规则不变。
- 标题工具或 F3 的“回到当前”重新对齐播放线并开启跟随; “适配所选/全曲”只改变视口。
- 谱面时间轴不再显示两侧进度拉条; 直接点击或拖动已有节拍标尺定位播放时间, 遵循当前吸附设置, 横竖布局均支持。总览区域保持不变。
- Shift 拖动谱面节拍标尺、谱面总览或 Autoplay 标尺设循环范围, 直接拖动黄色端点调整范围, Esc 取消修改; 其余位置普通拖动仍 seek。
- 谱面、Simai 与 Autoplay 轨道用黄色背景标出循环范围。开启循环后, 范围内开始播放会继续, 范围外则回到循环起点。
- 顶栏、播放菜单的“回到开头”和 Alt+Home 行为一致: 循环开启且正在播放时回循环起点, 暂停或未循环时回歌曲开头, 保留播放/暂停状态。
- Autoplay 定位线、谱面播放线和节拍标尺拖出时间方向的边缘后持续平移并 seek, 鼠标停住也继续;
  移回视图内或松开停止平移。
- “播放 > 循环选中”使用选中对象范围, 加前 0.25 秒、后 0.5 秒余量; 范围可在播放菜单输入。
- Autoplay 的片段、区间、绘制和 Tab 导航规则见 [Autoplay 操作](EDITOR_AUTOPLAY.md)。
