# 谱面与 Autoplay 编辑交互方案

状态: **已部分实施, 同时保留后续设计目标**。更新: 2026-10-16。
视觉及自由布局见 [工作台设计](EDITOR_WORKBENCH_DESIGN.md)。
现有操作以 [键盘说明](EDITOR_KEYBOARD.md)、[Autoplay 说明](EDITOR_AUTOPLAY.md)、
[模板说明](EDITOR_TEMPLATES.md)、[文件说明](EDITOR_FILES.md)、[Simai 文本](EDITOR_SIMAI.md)为准。

本文把已经确定的使用习惯保留下来, 同时提出更清晰的操作层级。
当前已接入自由分屏、显式焦点/F6、属性固定、历史、视口导航与循环范围,
以及 Autoplay 的片段总览、传感器区间、G/Shift+D 和 Tab 导航。
“保留”不表示所有边界情况已验证; 标为“提议”或“待实现”的行为仍不可依赖。
Autoplay 多选框选、跨归属转移、Pad 实时录制、独立方向键精修和草稿隔离试听
尚未实现。布局目前需要显式保存, 不持久化全部视口和偏好。
Primary = macOS Command / Windows 与 Linux Ctrl; Alt = macOS Option。

## 1. 操作模型

必须分清四个状态, 不再让一个坐标或标志同时承担所有职责:

| 状态 | 作用 | 不代表 |
| --- | --- | --- |
| 播放位置 | 全文档唯一时钟, Pad、音乐、核心、红线共享 | 当前选中的 note |
| 编辑光标 | 下一次键盘编辑/放置位置, 有时值和 lane/区域 | 当前选区 |
| 选择集合 | G/S/R、复制、批量属性的明确操作目标 | 鼠标悬停目标 |
| 活动区域 | 接收键盘与滚轮的编辑视图 | 另一份文档或核心 |

悬停只提供候选与临时高亮。鼠标移动不切换活动区域、不重置键盘事务。
显式点击或 F6 才转移区域焦点; 未确认草稿先处理, 不能被另一个区域悄悄接管。
同一帧的确认输入只能被消费一次, 不得继续触发新建或播放。

### 输入优先级

对话框/IME/文字输入 > 已捕获的拖拽或编辑事务 > 活动区域命令 > 全局命令。
菜单、工具按钮、快捷键调用同一条命令, 禁用原因一致。不能各自实现一遍行为。
正在拖动的对象保持捕获直到释放/取消, 指针出区域后仍可正确确认或取消。

## 2. 谱面: 选择与放置

### 鼠标

| 操作 | 行为 | 状态 |
| --- | --- | --- |
| 单击 note | 选择, 更新属性和 Tab 锚点, 不自动进入 slide 编辑 | 保留 |
| Shift+单击 | 追加选择 | 保留 |
| Primary+单击 | 切换该 note 的选中状态 | 保留 |
| 空白拖框 | 所有放置工具下均可框选; Shift 追加, Primary 减选 | 保留 |
| 选择工具下单击空白 | 清除选择, 更新编辑/Tab 参考点, 不自动 seek | 保留 |
| 放置工具下单击空白 | 在吸附后的指针位置开始或完成放置 | 保留 |
| 拖 note 头部 | 移动, 多选时保持组内相对关系 | 保留 |
| 拖 Hold/Star 手柄 | 直接调整对应时间, 无需先选中 | 保留 |
| 双击 Star 头 | 拉出同头新 slide, 经过与普通放置相同的阶段 | 保留 |
| 中键点 slide / E | 进入 slide 分段编辑 | 保留 |
| Alt+单击重叠对象 | 按稳定顺序循环候选, 不需要反复移动鼠标寻找中心 | 提议 |
| 右键 | 默认显示对象上下文菜单, 旧版快速删除可选兼容配置 | 提议, 待确认 |

命中范围与 note 实际显示尺寸相符。范围重叠时优先最近中心, 精确重叠再使用
稳定候选顺序。绘制前后关系按时值决定, 不能由创建顺序决定。

框选越界后持续滚动, 不能把框选起点改成屏幕坐标。可见细分与允许吸附的细分一致;
时间轴缩放不能把拖动或放置落点限制到另一套隐藏网格。

### 放置反馈与确认

- 空闲放置显示跟随鼠标且吸附到网格的虚影, 使用真实 note 的尺寸和锚点。
- 指针按下立即显示草稿, 提交后直接替换虚影, 不等待双击识别计时器或核心同步。
- 点击与框选用移动阈值区分, 不能为了识别拖拽而给确认后显示再加延迟。
- Tap/Touch 一次确认放置; 普通 Enter 不因操作系统按键重复而意外放一串。
- Hold/TouchHold: 固定头 -> 调尾 -> 确认。零时长可用, 虚影、正式图形、Pad 的
  头尾锚点与零时长基准形态一致; 不把持续时间 0 误画成消失的贴图。
- Star: 头 -> 虚线启动拍 -> slide 终点; Shift+Enter 确认当前连接段并继续。
- 同头 slide 使用同样的启动拍与尾端调整流程, 只突出当前编辑的轨迹。
- Hold/Star 手柄在未选中时也可命中; slide 尾端手柄位于实际结束 lane。
- Shift+D、粘贴、G/S/R 时只显示本次变换草稿, 隐藏普通放置虚影。
- 确认复制/变换的点击不能再次放置一个 note。
- Esc 取消当前子步骤或回到上一放置阶段, 不损伤已经存在的谱面。

### 选择与编辑层级

Touch/TouchHold 的属性区域显示实际 Sensor (A1-A8、B1-B8、C、D1-D8、E1-E8),
可以输入区域名或直接点击 Pad 感应区修改; 修改时间、持续时间或其他属性不会改变区域。
没有目标 note 时, Touch 工具下点击 Pad 设置下一次放置的区域, 虚影与放置使用同一值。
属性固定时 Pad 修改固定的 Touch。键盘模式同步区域光标。
Touch 的 Firework 可在属性中切换; Hold/TouchHold 尾端可直接拖回零时长。

谱面 -> Star -> 同头轨迹 -> 连接段, 使用短路径显示当前层级。
单击 Star 只选头; E 进入轨迹, Tab 切同头 slide, Primary+Left/Right 切连接段。
当前轨迹在谱面和 Pad 同步突出, 其余轨迹弱化但位置不变。
完整 slide 的归属、时值和渲染几何不因进入编辑层级改变。

属性栏默认跟随选择; 键盘光标模式下可直接预览候选对象, 不要求先选中。
“预览候选”和“已选 N 个”要有不同状态标记, 防止误以为属性属于整个选区。
固定属性对象后不再跟随光标, 必须有明显固定状态。
EACH 始终只读, 依照时值与星头关系自动计算, 不提供手动勾选。

## 3. 谱面: 键盘与批量编辑

### 保留的操作

| 按键 | 行为 |
| --- | --- |
| 方向键 / Primary+方向键 | 沿当前视图的时间轴和 lane 轴移动光标, 支持长按与斜向组合 |
| 加 Shift | 大步移动: 时间一小节, lane 四格 |
| 1..8 | 指定 lane; 在 slide 阶段表示端点 lane |
| Tab / Shift+Tab | 下/上一个 note, 支持长按, 使用最近鼠标点击更新后的锚点 |
| J | 输入小节/秒数并对齐光标、播放位置和视图 |
| Enter | 放置或确认当前步骤, 不穿透到下一事务 |
| F2 / Shift+F2 | 选中候选 / 切换候选是否加入选区 |
| Primary+A / Primary+Shift+A | 全选 / 清除选择 |
| Primary+Enter | 开始/确认键盘范围选择; Shift 版本追加 |
| G / S / R | 移动 / 只沿时间轴缩放 / lane 旋转 |
| Shift+D | 复制当前选择, 立即进入移动 |
| Shift+R | 重复已确认操作, 或由最近两次兼容放置推导下一次 |
| E / F7 / F5 | slide 编辑 / 手柄调整 / 当前对象属性 |
| Primary+C / X / V | 复制 / 剪切 / 粘贴, 键盘粘贴锚定光标 |
| Primary+Z / Primary+Shift+Z | 文档撤销 / 重做 |
| F8 / [ / ] | 吸附开关 / 调整细分 |

方向、Tab 导航同步预览播放时间并保留播放/暂停状态, 但光标在视口内时不移动视图;
只有越过边缘才滚动。Home/End、PageUp/PageDown 保留现有导航含义。
普通浏览滚动不自动 seek; 标尺点击、J、显式键盘定位才改变播放位置。

G/S/R 沿用鼠标与滚轮驱动, 也接受方向键、数值输入和 Enter。启动时显示变换
基点, S 不混入 lane 调整。变换中的滚轮只调整变换, 不再同时滚动或缩放视图。

### 删除范围

- 键盘光标模式: Delete/Backspace/D 删除候选, 指向空白不删除其他选择。
- Primary+Delete/Backspace 显式删除整个选择集合。
- 鼠标模式: Delete/Backspace/D 作用于选择集合, 不临时改成悬停对象。
- 删除、恢复、复制的目标在执行前可辨识, 可用一次撤销恢复。
- 模板实例与普通 note 使用不同的归属标记, 普通删除不静默变成删除模板定义。

### 重复与历史

- Shift+R 的放置参考只需要最近两个兼容对象, 属性相容且存在非零规律才继续。
- 删除对象同步从参考中移除, 重新使用仍存在的最新两个; 不足两个时不猜测。
- 复制移动确认后, 重复包含“复制 + 同一位移”, 不是只移动已有对象。
- 被取消的操作和只改变视图的操作不进入“重复上次编辑”。
- 一次拖动、一次完整 Hold/Star 放置、一次确认复制各占一个撤销步。
- 布局移动有单独的布局恢复命令, 不挤进谱面 Cmd+Z 的编辑历史。

## 4. Autoplay: 以动作区间为主要对象

片段总览和传感器区间已接入正式编辑器, 原始事件视图作为备选保留。
以下注明待实现的操作仍是设计目标; 当前完整入口见 [Autoplay 说明](EDITOR_AUTOPLAY.md)。

### 总览与精修

- 保留默认四条复用轨道: 顺序动作复用轨道, 双押/重叠占后续轨道。
- 轨道只用于排布, 不等于真实手指、传感器编号或核心事件归属。
- 总览将相关动作展示为片段, 能整体移动/复制; 同头 slide 分别标识。
- 单击片段只选择; 当前事件/区间在主轨道内显示可拖动本体与端点, 单区间片段直接选中该区间。
- 双击片段或 Enter 才展开可选精修栏, 只显示该片段使用的传感器行。关闭精修栏保留当前选择与绘制状态。
- 匹配的 Press/Release 组成可拖动区间; 中间拖动整体, 两端各调一个时刻。
- Click 是独立标记; 原始事件模式保留孤立 Press/Release 和特殊序列。
- 配对依据真实输入状态与稳定事件归属, 不凭相邻绘制顺序配对, 不跨 note
  把两个刚好同区的事件连成一条。跨组有效输入仍由实际播放规则处理。
- 零时长区间不静默变成 Click; 两端用分离命中区或端点选择菜单编辑。
- 无法配对的事件保留为独立标记, 不为“看起来整齐”自动改写事件; 专门的问题诊断标记待实现。

总览片段可以聚合多个核心所属部分, 但修改必须映射回原 Note ID、角色、slide、
segment 等归属。展开、折叠、换显示轨道都不重新生成这些 ID。

### 操作表

| 操作 | 选择模式 | 绘制模式 |
| --- | --- | --- |
| 点击片段/区间 | 选择并检查, 不 seek | 已有对象仍可选择, 不在其上误造事件 |
| 点击空白 | 清除选择, 不创建 | 主轨道按 Click/Hold 新建事件, 不要求先选 note; 精修栏取所在传感器 |
| 拖空白 | 框选/Shift 追加待实现, 当前不创建 | 主轨道或精修栏直接拉出 Press-Release |
| 拖区间中间 | 整体移时 | 同左 |
| 拖左右端点 | 调整按下/释放时间 | 同左 |
| 点击标尺 | seek | seek, 不新建事件 |
| 点击 Pad 感应区 | 修改选中区间的区域; 未选事件时只设置新建区域 | 在红线处添加 Click 或一个细分长度的 Hold, 未指定归属时创建独立片段 |
| Click/Hold 工具按钮 | 转换选中的事件/区间; 未选事件时仅设置新建类型 | 只设置后续新建类型, 不修改刚放置的事件 |
| Shift+D / G | 复制后移动 / 移动 | 事务期间暂时屏蔽绘制 |
| Delete | 删除明确选中的事件/区间/片段 | 同左 |
| Esc | 取消草稿, 再清选择/退出精修 | 取消草稿, 再退出绘制 |

点击空白清除对象选择后, 展开的片段可以作为精修范围保留, 但只在显式绘制模式
下允许新建; 范围标题始终显示归属。关闭精修栏不等于清除选择, 主轨道仍标明选中片段。
主时间轴标题提供选择、绘制、Click/Hold 和新增入口, D 不再自动展开精修栏。
创建时值取吸附后的鼠标位置, 区域取最后显式点选的 Pad 感应区; 精修栏则取传感器行。
无选择时按 D, 每次绘制创建独立片段, 不需要谱面中已有 note; 连续放置不会自动追加到刚创建的片段。
先明确选择片段再按 D 则向该归属追加, 不取鼠标下的排布轨道, 不继承上次选中事件的属性。
独立片段参与播放与 seek, 保存在原生 JSON 中; 删除最后一个事件后移除片段, Esc 取消草稿不留下空片段。
感应区直接在 Pad 点选, 外圈 K1-K8 保留按钮输入, 内圈按真实 SVG 感应区命中。
正常视图改区域时同步修改 Press/Release; 原始事件视图只改当前事件。
选择模式下 Click/Hold 高亮反映选中事件的实际类型; Click 转 Hold 保留原始起点和区域,
向后延长一个细分; Hold 转 Click 保留按下时间并移除配对 Release, 选中任一端点均可转换。
每次转换是一步撤销, 重复选择当前类型不重置时长或添加历史; 原始事件视图继续单独编辑 Click/Press/Release。
绘制模式下点 Pad 会在红线处新建, 直接在主轨道显示区间手柄, 不自动展开精修栏, 不向判定预览发送实时触摸。
实时按住/释放 Pad 来录制持续时间的显式录制模式仍待实现。

### 防误操作

- 区间端点最小命中区约 18-22 逻辑点, 不随着时间倍率缩小。
- 两端靠近时使用上下错开的端点柄, 不移动它们的真实时间坐标。
- 相邻区间命中范围冲突时使用同一传感器下的子行, 拖动中保持行分配。
- 正常视图删除任一长按端点会删除整个区间; 原始事件视图仍可单独删除事件。
- 同像素候选循环/候选菜单待实现; 当前近距离区间端点使用分离命中区, 可用 Tab 精确切换。
- 缩小时显示片段与概况; 放大或选中后显示端点与区域标记。
- 拖动期间布局固定; 确认后优先保留原轨道, 只重排发生冲突的片段。
- 不可把事件拖入另一 note 改归属; 显式“转移到...”操作待实现。
- 复制后的事件仍属于原归属; 显式跨 note 复制与相对时间偏移待实现。
- 删除整片段表示禁用该组事件; “恢复生成默认”与删除是两个不同命令。
- 对片段做恢复/禁用/整体变换前, 明确展示其覆盖的核心所属部分。

### 键盘精修

Tab/Shift+Tab 已可在总览遍历片段, 精修时遍历当前片段的事件或区间端点, 支持长按。
普通视图中的 G、Shift+D 已可移动/复制片段、区间或单个事件, 跟随鼠标和滚轮;
变换中左右键按细分微调, Shift 加速, Enter 或单击确认, Esc 取消。
原始事件视图保留逐事件拖动, 不提供片段 G/Shift+D。R 不绑定动作。
空闲时直接用方向键微调、上下键选择传感器行和多选批量精修仍待实现。

## 5. 导航、缩放与试听

### 时间倍率与可见范围

- 谱面与 Autoplay 的 Primary+滚轮、触控板捏合都固定鼠标下的时间点; Autoplay
  标题栏数值缩放固定当前视口中心。缩放不关闭跟随, 也不改变播放时间; 谱面保留缩放后的播放线位置。
- 两种编辑器都支持按住中键后偏离按下点持续滚动, 偏移越远速度越快; 回到原点
  停止, 松开结束。谱面纵向版用上下方向, 横向版与 Autoplay 用左右方向。中键轻点
  Slide 轨迹仍进入编辑, 已经滚动的手势不会触发编辑。
- 两种编辑器都支持 Shift+滚轮平移时间。Autoplay 中键与平移不 seek, 普通滚轮滚动轨道。
  谱面开启跟随时, 中键、Shift+滚轮及普通滚轮同步移动播放时间; 关闭跟随时只浏览视图。
- Autoplay 标尺定位线与谱面播放线拖出时间方向边缘后持续平移并 seek; 鼠标停在边缘外
  也继续, 移回视图内停止平移。拖动不关闭跟随, 松开后按当前工作区的跟随规则恢复。
- 正在 G/S/R 或抓住端点时, 滚轮由当前事务消费, 不触发普通视图操作。
- 放大只改变时间间隔, 不改变贴图尺寸、端点尺寸、文字或属性面板大小。
- “适配选中”“适配全曲”“回到当前”是独立命令, 不偷偷重置用户倍率。

### 跟随模式

提供明确的跟随开关, 手动浏览、缩放或编辑不自动关闭它。
Autoplay 暂停时可以自由浏览; 播放线在有效时间区域的左半屏时视图不动, 到达中线后
用约 200ms 平滑开始滚动, 随后保持播放线居中。已经超过中线, 或 seek/循环后落在
左侧屏外时, 从当前视图平滑跟上, 不瞬移。暂停立即停止过渡; 正在拖动、缩放或编辑
时手势优先, 结束后重新按中线规则恢复。开启跟随不主动居中, “回到当前”才立即居中。
此过渡只改变视图, 不 seek、不改变播放时钟。
谱面跟随在暂停和播放时都生效: seek 后视图同步移动, 中键或滚轮平移时带动播放时间。
缩放保持鼠标锚点, 不 seek。键盘光标独立浏览和显式适配范围仍可暂时脱离跟随,
“回到当前”恢复默认播放线位置。

### 播放与草稿

现状: 某些未确认放置/变换会占有 Space。提议: 非文字输入状态下, Space 始终
控制播放/暂停, 即使正在放置也不作为确认动作; 试听只使用已提交谱面, 草稿保留。

这需要草稿与已提交数据隔离, 是待确认的行为变化, 不能只放开快捷键而播放半成品。
拖动过程中试听不移动被抓取对象的屏幕锚点, 文本框/IME/对话框仍有输入优先权。

### 循环与判定辅助

- “循环选中”自动包围片段, 当前使用固定的前 0.25 秒、后 0.5 秒余量; 可配置余量待实现。
- 谱面时间轴不显示两侧进度拉条; 使用已有节拍标尺的隐藏交互区域点击/拖动 seek, 坐标对应当前可见拍点并遵循吸附设置, 横竖布局均支持; 总览区域保持不变。
- Shift+拖谱面节拍标尺、谱面总览或 Autoplay 标尺创建循环范围, 拖动黄色端点调整范围, Esc 恢复原范围; 其余位置普通拖动仍 seek。
- 谱面、Simai 和 Autoplay (含展开轨道) 以黄色背景显示循环范围。开启循环后, 范围内开始播放保持当前位置, 范围外或播放到终点时回到循环起点。
- 判定覆盖层沿用核心真实元数据; 缺失时显示不可用, 不猜测窗口。
- Hold 显示头部判定及有效保持要求; slide 只在完整轨迹末端显示窗口。
- 判定窗口是只读辅助, 不自动纠正用户的触摸时间。

## 6. 设置、文件与反馈

- 保留 Primary+S 保存、Primary+Shift+S 另存、Primary+Shift+E 导出、Primary+O 打开。
- 保存完整原生 JSON 以保留模板与 Autoplay; Simai 导出明确不包含这些编辑元数据。
- 放置/变换等未确认草稿不随保存隐式写入; 保存时要求完成/取消草稿, 不悄悄丢弃它。
  Simai 文本采用明确的“应用并保存”: 保存/另存/导出前校验并应用全文, 失败则不写盘并保留草稿。
- 修改后 note/事件先本地立即显示, 核心后台同步; 状态栏区分“未保存”与“同步中”。
- 核心未同步时可导航、选择和撤销; 实现允许时继续编辑并合并最新请求。不能把
  旧核心结果当成最新谱面, 状态过期的播放/判定动作需明确禁止或等待。
- 失败保留用户编辑并提供重试; 不以成功提示掩盖未写盘或未同步。
- F3 为统一命令搜索, F1/Primary+, 打开设置, F12/? 打开上下文帮助。
- F6/Shift+F6 遍历可见区域, 不占用谱面中已用于 note 导航的 Tab。
- 所有布局命令也进入 F3/菜单, 不要求只能拖拽才调整工作区。
- 新键位加入冲突检测; 不直接覆盖现有用户键位, 功能键提供菜单与命令搜索替代。

### Simai 与分区拖拽

- 工作区增加 Simai 预设, 分区类型菜单也能独立添加 Simai 文本编辑器。
- 编辑当前难度的正文, 不包含 `&inote_N=` 等 maidata 字段; Primary+Enter 应用,
  Primary+S 应用并保存, 标题重新读取按钮放弃文本草稿并从当前谱面生成正文。
- 文本输入时 Enter、Space、方向键、Tab、复制和撤销交给文本框, 不触发谱面放置/播放。
- 应用是一次谱面历史操作; 解析失败不改谱面。文本未应用时的图形修改不会覆盖草稿,
  再应用前必须处理冲突。切换工作区或关闭分区不丢失草稿。
- 拖动分区标题到其他分区的边缘拆分停靠, 到中央交换; Esc/右键取消。
  拖拽及释放帧不向底层谱面传递放置点击, 锁定布局或编辑事务中禁止拖分区。
