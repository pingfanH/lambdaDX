# 编辑器工作台: 设计与实施状态

状态: **正式编辑器已接入工作台和首批人体工程学交互**。更新: 2026-10-16。

正式入口为 `lambda_dx_editor`, 独立的 [UI 预览 bin](EDITOR_UI_PREVIEW.md)仍保留为样稿。
操作规则见 [交互方案](EDITOR_INTERACTION_SPEC.md); 已有编辑功能见
[键盘操作](EDITOR_KEYBOARD.md)、[Autoplay](EDITOR_AUTOPLAY.md)、
[设置](EDITOR_SETTINGS.md)。下方“当前实现”是使用说明, 后续章节仍包含待实现的设计目标。

## 当前实现

- 正式 editor 使用紧凑炭灰主题、单行全局顶栏、合并工具的分区标题和悬浮 note 工具条。
  菜单与悬浮工具半透明, 标题与画布实色; 无实时模糊或装饰渐变。
- 提供“谱面 / Autoplay / 组合”三套工作区。每套布局在本次运行中独立保留,
  切换不重新打开文档; 谱面和 Autoplay 时间轴各自保留缩放与视图位置, 共享播放时钟。
- 七种区域: 谱面、Pad、属性、总览、Autoplay、模板 / Scene、历史。
  每种类型只有一个实时区域; 类型菜单选中已存在的区域时交换位置, 不生成重复视图。
- 拖动分隔线调整比例; 标题左侧类型图标替换区域; 右侧菜单提供向右/下拆分、交换与关闭。
  最后一个区域不能关闭。标题最大化图标或双击标题空白处可最大化/恢复。
- “视图”菜单控制区域可见性; “视图 > 布局”可添加区域、保存/恢复布局、
  重置当前工作区和锁定结构。锁定后仍能调比例, 但不能拆分、交换、关闭或替换类型。
- 点击区域或 F6 / Shift+F6 按屏幕顺序切换焦点; 点击谱面或 Autoplay 切换编辑作用域,
  属性随之切换; 鼠标仅悬停不会抢走焦点。
  放置、拖拽、框选和模态编辑期间暂时禁止切换布局, 先完成或取消当前操作。
- 保存、导出、模板、原有 note 编辑与快捷键、真实 Pad、核心同步和 Autoplay 事件编辑
  继续使用现有实现。没有把原型中的示例数据、演示时钟或简化判定接入正式运行时。
- Autoplay 默认显示聚合片段; 单击或 Enter 展开传感器精修, 区间整体移动与两端调整
  分开。G / Shift+D 支持移动 / 复制后移动, 一次确认一个撤销步, 原始事件视图仍可切换。
- 属性区显示对象贴图、类型、ID 及候选/多选状态, 可固定单个 note; 固定对象删除后
  显示失效状态, 不跳到另一对象。Autoplay 属性使用 Sensor / Press / Release 三列。
- 历史区域显示真实文档撤销/重做位置, 可点击跳转。布局变化不进入谱面编辑历史。
- 标题工具和 F3 提供适配所选、全曲、回到当前及跟随开关。谱面与 Autoplay 都支持
  中键按住后按离原点的距离调速滚动、Shift+滚轮平移时间, 都不 seek。谱面纵向版按
  上下方向滚动, 横向版与 Autoplay 按左右方向; 回到原点或松开停止。谱面普通滚轮
  纵向 seek、横向浏览时间, Autoplay 普通滚轮浏览轨道。两者手势缩放固定鼠标下的时间点; 播放定位线
  拖出时间方向边缘持续平移并 seek。手动浏览和缩放暂停跟随, 各自保持倍率和视口。
- 播放菜单提供循环开关、范围及循环选中; Shift 拖谱面总览或 Autoplay 标尺设范围,
  Esc 取消。循环选中使用固定的前 0.25 秒、后 0.5 秒余量。
- 显式“记住当前布局”写入 `output/editor_workspaces.json`, 重启后恢复分屏结构与比例。
  格式带版本校验; 无效配置备份为 `.invalid.json` 后回退预设。

当前边界: **布局需显式保存, 不自动保存视口倍率、跟随状态或所有偏好**。同类型多视图、
独立原生窗口、真实磨砂、设置分类重构、Autoplay 多片段框选/跨归属转移、Pad 绘制录制
以及“保留草稿并只试听已提交谱面”仍未实现。下文包含这些后续目标, 不代表已全部可用。

启动: `cargo run --bin lambda_dx_editor`。可用 `MAI2_EDITOR_WORKSPACE=autoplay` 或
`MAI2_EDITOR_WORKSPACE=combined` 选择初始工作区; 不设置时使用谱面工作区。

## 1. 设计方向

根据预览反馈和用户提供的 Bevy Editor SVG, 方向调整为
**紧凑分层的炭灰工作台 + 局部半透明悬浮工具 + 单编辑器分屏**。
从 Blender 借鉴区域拆分、编辑器类型切换和工作区; 从 VS Code 借鉴
紧凑信息密度、命令搜索和明确的焦点。保留谱面工具自己的 note 贴图与空间语言。
每个区域只显示一个编辑器, 不使用标签组或在区域内切换 Tab。

已确认的视觉约束: 左侧工具条在画布内悬浮; 使用不偏色的炭灰材质, 不用纯黑;
按钮小而扁平, 没有与背景明显隔离的常驻色块和描边。预览与正式编辑器均采用
单行全局工具, 每个分区的工具并入标题行。
最新参考为用户提供的 `Tabs as Workspaces (Done).svg`, 对应 Figma 节点 `6564-7869`。
本轮采用深色窄标题、略亮的内容面和紧凑对齐的属性分组, 取消此前的双边渐变,
透明仅保留在悬浮工具、菜单和临时窗口。层次来自灰阶、间隔和内容组织,
不靠冷暖偏色、按钮底框或整面彩色背景。保留用户此前的单编辑器分屏要求,
不照搬参考图中的区域标签组、左侧场景树或 3D 内容。

需要改善的不是单纯的配色, 而是工作区层级、信息密度、操作对象和反馈:

- 主要时间轴获得最多空间, Pad、属性、模板是可重新安排的独立区域。
- 页面采用连续工作表面和细分隔线, 不把每个设置或区块装进浮动卡片。
- 高频操作靠近编辑内容, 低频配置进入设置; 不把全部功能堆进顶栏。
- 面板标题、当前对象、当前编辑层级清楚, 但不挤占画布。
- 布局变化不改变音符大小, 不触发 seek, 不重置判定或重建核心。
- 任何布局操作都能恢复, 键盘操作不依赖鼠标恰好悬停在哪个区域。

### 风格候选

| 方向 | 表现 | 取舍 |
| --- | --- | --- |
| A. Bevy 式紧凑灰阶 + 局部透明, 当前方向 | 深色标题、连续画布、对齐属性行、浮层轻投影; 结构表面不透明 | 轻量透明绘制, 磨砂后置 |
| B. 同色实底, 可访问性备选 | 保持相同尺寸与层级, 关闭透明 | 长时间编辑或降低透明效果时使用 |
| C. 真实磨砂, 后续可选 | 在 A 的局部浮层增加背景模糊 | 需先验证性能, 不默认扩大透明面积 |

当前 A 采用紧凑、扁平的控件。不是整页透明, 不引入全页装饰渐变、发光、
背景光斑或大圆角; 标题和工具条不再使用装饰渐变。以下数值需样稿确认。

## 2. 视觉规范草案

### 表面与语义色

| Token | 初始值 | 用途 |
| --- | --- | --- |
| Window | `#171717` | 窗口底色、分屏间隙 |
| Header | `#1F1F1F` | 紧凑的全局顶栏和区域标题, 不透明 |
| Recessed | `#222222` | 内嵌的 Pad / 总览背景 |
| Canvas | `#272727` | 谱面与事件时间轴底色 |
| Lane | `#292929` | 交替 lane / 轨道, 不复用辅助面板色 |
| Panel | `#282828` | 略亮的不透明属性、模板、历史表面 |
| FloatingGlass | `#2B2B2B`, 约 91% 不透明度 | 菜单、设置窗口与悬浮工具条 |
| Control | `#343434` | 需要底色的输入控件, 不用于普通按钮 |
| Border | `#3D3D3D` | 网格强线、必要分隔; 不用于普通按钮描边 |
| Text | `#DCDCDC` | 主文字 |
| TextSecondary | `#A0A0A0` | 次级数值、标签 |
| Selection | `#79B8F4` | 选中轮廓、键盘焦点 |
| EditCursor | `#E5C37A` | 编辑光标, 与播放线区分 |
| Playback | `#F16D7A` | 红色播放线 |
| ActiveInput | `#6BC8AF` | 正在生效的触摸区间 |

所有中性材质使用等值 RGB 的黑灰色系, 无蓝灰或暖灰偏色, 无纯黑表面。
标题与编辑器类型图标保持中性, 强调色只标识对象类型、选择与播放状态, 不把整个面板染色。
Note 继续使用项目自己的贴图; EACH、Break 等颜色含义不被主题替换。
选中、焦点、悬停分别用实线、标题标记、细轮廓区分, 不能仅靠颜色。
标题与图标保持清楚, 工具和次级数值适当降低亮度; 网格细线弱于小节线。
悬浮工具和菜单允许柔和的局部投影, 普通按钮和整个分区不使用投影。

### 磨砂的边界

- 半透明使用位置: 菜单、命令搜索、临时属性浮层、悬浮工具条。
- 不使用位置: 全局顶栏、区域标题、note 网格、波形、Autoplay 事件区、常驻属性数值区、Pad 判定内容。
- 当前预览材质: 标题为实色, 浮层约 91% 炭灰底色, 仅浮层带轻投影。
  不再使用双边渐变、标题亮边或面板整体阴影。
  无实时背景模糊, 不读取屏幕纹理, 不增加模糊绘制步骤。
  不采用纯黑, 不用浅灰按钮色块或明显边框制造材质感。
- 文字、图标、手柄始终不透明; 不让细网格透到文字下面。
- 模糊只处理应用内部背景, 不默认读取桌面或依赖 macOS 特有材质。
- 设置提供“实色 / 半透明 / 磨砂”和“减少透明效果”; 高对比模式使用实色。
- 未完成渲染方案验证前, 不承诺实时磨砂没有性能成本。先保证播放与输入响应。
- 降级为实色时尺寸、颜色语义、布局完全不变。

### 尺寸与控件

- 默认正文、菜单/面板标题 12 逻辑点, 次级数值 11; 不随窗口宽度缩放字号。
- 紧凑控件高 22-24, 图标 14-15, note 工具命中区 26, 贴图 20。
- 菜单/工作区/播放共用一行约 28 高的全局顶栏; 区域标题与工具共用一行 26 高, 状态条约 20。
- 宽度不足时工作区切换折叠为菜单, 次要播放控制进入 Playback, 区域工具进入溢出菜单; 不换行。
- 普通按钮默认透明无描边, 悬停/按下只叠加微弱亮度; 选中状态靠图标色和细标记。
  不让 File/Edit、缩放、播放等按钮各自形成有边框的方块。
- 结构间隙 3, 细分隔线 1, 可拖动命中带 6-8; 小手柄的命中区大于视觉尺寸。
- 停靠面板直角相接; 控件圆角 2, 菜单与浮层圆角 4。
- 文字字距为 0; 时间和数值使用等宽数字, 标签与数值两列对齐。
- 按钮优先使用一致的图标资源; 工具类型使用 note 贴图, 不用字母代替。
- 二选一状态用切换开关, 模式用分段控件, 选项用菜单, 数值用可键入的步进框。
- 图标提供悬停提示和可访问名称; 不在画布写教学说明或堆快捷键提示。
- UI 缩放、谱面 note 尺寸、Pad 内容缩放、时间轴时间倍率是四个独立设置。

## 3. 工作台结构

全局区域只有两个: 合并菜单/工作区/播放控制的单行顶栏, 以及底部状态栏。
中间所有内容是可组合区域, 不是写死的“左栏/右栏/底栏”。
每个区域只有一行“类型/标题 + 局部工具 + 布局动作”, 不另设第二条工具栏。

### 可放入区域的编辑器

| 编辑器类型 | 内容 |
| --- | --- |
| 谱面 | 纵向或横向 note 时间轴, 每个视图独立倍率与滚动 |
| Pad | 当前全局播放时刻的实时预览, 可显示判定覆盖层 |
| Autoplay | 少量复用轨道及按需展开的传感器事件 |
| 属性 | 活跃对象的属性, 可固定到指定对象 |
| 资源/场景 | 文件、难度、模板库、模板实例; 按编辑器类型单独显示 |
| 历史 | 可读的已确认编辑动作和撤销位置 |
| 总览/波形 | 全曲定位、循环范围和音频波形 |

### 区域操作

1. 拖分隔线调整大小, 不更改字体或 note 大小。
2. 每个分屏严格只有一个编辑器, 标题左侧的类型菜单直接替换该区域, 不增加标签。
3. 面板菜单提供左右/上下拆分、切换编辑器类型、移动、交换区域、关闭。
4. 关闭区域时收拢对应分屏, 不删除编辑对象; 最后一个区域不可关闭。
5. 双击标题条空白处或点击最大化图标临时最大化; 再次操作恢复原布局。
6. 可复制同一谱面视图, 一边看全局一边看细节; 数据同步, 视图倍率独立。
7. 布局菜单提供保存、另存、重命名、恢复预设及单独的“撤销布局更改”。
8. 可锁定区域结构, 仍允许调整分隔比例、编辑内容与滚动, 禁止拆分/交换/关闭/类型替换。

角落拖拽拆分可以作为后续熟练操作, 不能是唯一入口。
第一阶段支持窗内拆分、区域交换和区域类型替换; 不引入多标签容器。
独立预览通过标题右侧菜单提供拆分/交换/关闭, View 菜单添加独立分屏。
窗内悬浮编辑区域为第二阶段, 与画布内的小型悬浮工具条不同。
真正脱离主窗口、多显示器原生窗口需要单独验证, 不能用窗内悬浮冒充已支持。

### 焦点、状态与持久化

- 点击或 F6 选择活动区域; 单纯移动鼠标不夺取键盘焦点。
- 面板类型切换保留对应视图状态; 关闭面板不删除谱面对象。
- 同一文档共享数据、历史、播放时钟和核心会话; 同类型视图共享对象选择。
- 谱面 note 选择与 Autoplay 事件选择分开, 属性默认跟随最后活跃编辑器。
- 属性可固定对象; 固定对象被删后显示失效状态, 不跳到另一个对象上继续编辑。
- 工作区切换只改变布局与视图状态, 不重建核心、重新载谱面或重启音乐。
- 未确认草稿不因切换布局被悄悄提交或丢弃; 跨编辑作用域前明确确认/取消。
- 布局保存到用户偏好, 不进入谱面 JSON, 不使谱面出现未保存标记。
- 保存分屏比例、区域类型、区域位置、可见状态和各视图参数; 使用版本化格式。
- 窗口变小优先最大化主要编辑器或收起次要区域, 不缩小字体或自动合并为标签。
- 损坏或不兼容的布局可回退到预设, 保留原配置备份。

## 4. 默认布局提案

这是默认入口, 不是功能限制。所有预设都能改成自己的布局。

### A. 谱面编辑, 推荐默认

```text
文件 编辑 视图 播放 | 谱面 Autoplay 联合 | 播放 时间 循环 速度 | 布局 设置
+---------------------------------------------+----------------------+
| 谱面: 纵向/横向  工具  吸附  细分  缩放      | Pad 预览             |
|                                             |                      |
|                 note 时间轴                 |                      |
|                                             +----------------------+
|                                             | 属性                 |
|                                             |                      |
+---------------------------------------------+                      |
| 总览 / 波形 / 循环范围                       |                      |
+--------------------------------------------------------------------+
保存状态 / 核心同步状态 / 所选数量 / 时值与 lane
```

- 标准窗口约 72% 宽给谱面、28% 给右侧, 右侧 Pad / Properties 约 46:54。
- 模板/历史从区域类型菜单进入, 或拆成独立区域; 左侧 note 工具条浮在谱面画布内,
  只占工具实际内容高度, 不使用贯穿画布的侧栏底色。
- 总览只在主谱面下方, 初始占左侧约 10% 高度, 右侧检查区贯穿工作区; 不横切整个窗口。
- 宽屏可把右下属性拆到最右列, Pad 单独放中间; 不强制自动变成三栏。
- 对比当前左右近似等宽分配, 主要增益是完整的谱面编辑空间和可调整的右侧。

### B. Autoplay 精修

```text
+---------------------------+----------------------------------------+
| Pad 预览                  | 属性 / 当前 note 与事件归属            |
+---------------------------+----------------------------------------+
| Autoplay: 选择/绘制   吸附   细分   缩放   跟随                     |
| 标尺 / 循环范围                                                    |
| 轨道 1   [Tap]     [Slide................]             [Touch]      |
| 轨道 2             [Hold...........]                              |
| 轨道 3                                                            |
| 轨道 4                                                            |
| 选中片段展开: B1 [======]  C [=======]  B5 [=====]                  |
+--------------------------------------------------------------------+
```

- 下方轨道区默认约 60%-65% 高, 保留四条复用轨道。
- 精修展开实际需要的传感器行, 不为每个 note 永久创建一行。
- Note、同头 slide、连接段的归属不因片段折叠或轨道排布改变。

### C. 联合检查

上半部分“谱面 + Pad”, 下半部分 Autoplay; 属性通过替换区域或额外分屏进入。
同一红线与 note ID 联动, 不使用两套互相漂移的播放时钟。用于边改谱面边检查输入。

### 小窗口与最小尺寸

- 以 1440x900、1280x720、1920x1080 逻辑尺寸检查默认布局。
- 谱面区域建议最小宽 360、高 300; 属性建议最小宽 240; Pad 建议至少 240 方形。
- 不满足最小尺寸时先收起资源、总览和属性区域, 必要时切单区域工作模式。
- 触摸设备使用舒适密度, 不把桌面密集布局整体等比压缩。
- 窗口调整后重新计算视口锚点, 保持正在编辑的内容可见; 不改全局时间。

## 5. 顶栏、属性与设置

### 属性密度

Properties 标题行仅放区域名和动作, 当前对象的贴图、类型、ID 放在内容顶部。
Timing / Autoplay 用紧凑的可折叠分组, 分组只带标题条, 不包成独立卡片。
字段标签与 22 高数值输入框保持两列对齐, 输入框可以有轻微底色, 普通命令按钮仍透明。
传感器区间用 Sensor / Press / Release 三列, 删除与信息无关的状态装饰。
Autoplay 片段使用中性底色和窄类型色标, 蓝色轮廓仅用于当前选中对象。

### 信息归属

| 位置 | 应包含 | 不应包含 |
| --- | --- | --- |
| 全局顶栏 | 文件、编辑、视图、播放菜单、工作区、布局与设置 | 全部 note 属性的常驻按钮 |
| 顶栏内的播放控制组 | 播放/暂停、位置、循环、速度; 次要项进入播放菜单 | 每条事件的动作和区域, 第二条播放栏 |
| 面板标题行 | 标题、工具、吸附、细分、朝向、局部缩放; 窄屏时使用工具菜单 | 音效与核心调试参数, 第二条工具栏 |
| 属性 | 所选对象的可编辑值与只读归属 | 长篇说明、全局偏好 |
| 设置 | 外观、布局默认值、输入、音频、预览与核心 | 当前 note 的时间/lane |
| 状态栏 | 保存失败/同步中/未保存、焦点对象、选择数 | 反复滚动的教学提示 |

### 设置界面

采用可调整大小的单一设置窗口: 左侧类别、中间搜索与设置列表, 不层层弹窗。
类别为外观、工作区、输入与快捷键、时间轴、Pad 与判定、音频、Autoplay/核心、文件。
每个值显示作用范围: 当前视图、工作区或全局默认; 同一个开关只有一份状态。

UI 偏好即时生效并保存; 改动判定/播放参数采用明确的应用动作, 不在拖滑杆每一帧
重建核心。失败保留旧有效值并允许重试。快捷键设置检测冲突并提供恢复默认。

| 阶段 | 内容 | 进入条件 |

| D0 | 操作与布局文档, 收集风格反馈 | 本次 |

实现前先确定可替换的区域容器边界, P0 不再新增写死的左右面板比例。

渲染器现成能力。多个 Pad 视图不能重复推进核心或重复播放音频。

每阶段只做相关编译/最小检查, 主要体验交给用户试用, 不默认扩展成大规模测试工程。

## 7. 参考与实现入口

官方参考只用于布局与可读性原则, 不要求逐像素复制其视觉或快捷键:

- [Bevy Editor, Tabs as Workspaces](https://www.figma.com/design/fkYfFPSBgnGkhbQd3HOMsL/Bevy-Editor?node-id=6564-7869): 本轮直接读取用户提供的同名 SVG 导出, 用于密度、灰阶和属性分组参考; 不复制区域标签组。
- [Blender Areas](https://docs.blender.org/manual/en/3.3/interface/window_system/areas.html): 区域拆分、合并与编辑器组织。
- [VS Code Custom Layout](https://code.visualstudio.com/docs/configure/custom-layout): 标签分组、停靠、布局恢复与键盘移动视图。
- [Apple Sufficient Contrast](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/sufficient-contrast-evaluation-criteria/): 透明背景也需要验证文字、图标与状态对比度, 提供减少透明效果。

现有实现入口:

- `editor/src/theme.rs`: 样式 token。
- `editor/src/ui/workbench.rs`, `ui/workbench/persistence.rs`: 单编辑器区域、分屏、工作区与布局持久化。
- `editor/src/ui/layout.rs`, `editor/src/ui/mod.rs`: 区域几何、输入作用域和真实内容挂载。
- `editor/src/ui/toolbar.rs`, `editor/src/ui/inspector.rs`: 全局入口与属性。
- `editor/src/autoplay_editor.rs`, `autoplay_editor/clips.rs`, `autoplay_editor/inspector.rs`: 独立视口、片段/区间编辑与事件属性。
- `editor/src/ui/history.rs`, `ui/navigation.rs`: 真实编辑历史和视口导航。
- `editor/src/keyboard.rs`, `editor/src/keyboard/panels.rs`: 焦点、命令与快捷键。
- `editor/src/runtime.rs`, `editor/src/runtime/sync.rs`: 运行时与核心同步边界。
