# Editor / Player 网络预览

Editor 和 Player 是两个独立进程, 可以在同一台电脑或同一局域网的不同设备上运行。
默认使用 Rust 判定后端。
自动同步使用第 3 版连接协议, Editor 和 Player 需要一起更新后重新连接。

## Editor 搜索 Player

1. 启动 Player, 打开“设置 → 网络预览”, 点击“允许 Editor 搜索连接”。
2. Editor 顶栏“游玩 → 搜索 Player 设备”。搜索约需两秒。
3. 首次连接输入 Player 显示的六位配对码, 点击对应设备的“连接”。
4. 连接成功后, 在“游玩”菜单选择从头或从当前位置游玩、自动预览。

两端都会记住设备身份; 发起连接的一端保存可重连的地址与凭据, 下次可点“重连”。
IP 地址变化时, Editor 重新搜索同一设备即可复用配对凭据连接新地址。
被连接的一端会显示设备记录, 由原发起端重连。移除设备删除本端记录, 不会撤销另一端保存的凭据。

## Player 扫码连接 Editor

1. Editor 顶栏“游玩 → 开启连接 / 显示二维码”。
2. Android Player 打开“设置 → 网络预览 → 扫描 Editor 连接二维码”。
3. 首次使用授予相机权限, 对准二维码即可连接。成功后相机自动关闭。
4. 连接成功后由 Editor 发送预览。Player 会记住 Editor, 后续可直接重连。

相机权限被拒绝或设备无相机时, Editor 可“复制连接码”, Player 用“手动输入连接码”粘贴。
桌面 Player 的网络设置同时提供连接码输入与二维码图片路径导入。

## 预览与远程控制

- 连接后默认自动同步 Editor 中的谱面, 首次同步在 Editor 当前位置显示为暂停预览。后续增删 Note、撤销/重做、BPM、音频延迟、模板和 Autoplay 修改都会自动发送, 不需要保存或再次点击预览。
- 连续修改会短暂合并, 每次操作结束约 150–250 ms 后发送最新版本; Player 在后台重新准备判定, 准备期间短暂停住。未开启进度跟随时, 完成后保留自己的播放位置、暂停/播放状态、速度和 Autoplay。手动选择“从头/当前位置游玩”仍会开始播放。
- 未完成的拖拽、放置和未应用的 Simai 草稿不会同步。可在 Editor“游玩”菜单取消“自动同步编辑到 Player”, 继续使用手动发送。
- 发送 Editor 当前内存中的 canonical chart, 包括未保存 Note 修改、模板和 Autoplay 配置。有效 Simai 草稿会先应用。
- 音频以带 SHA-256 校验的 PCM 数据传送, 不依赖共享路径。单份音频最多 256 MiB。
- 同一连接重复预览会复用 Player 已缓存的同一音频; 重启 Player 后会重新传输。
- 从当前位置播放使用谱面时间; `first` 仍只用于音频延迟。判定在后台准备, 首帧呈现后再开始计时和播放音频。
- 从头播放、重播及回到开头从第 0 小节开始, 按初始 BPM 预备一小节。第 1 小节仍为谱面 0 秒, Note 和 `first` 不作平移; 进度条可拖回第 0 小节, 预备期间显示负时间。
- Editor 可暂停、继续、重播、停止、让 Player 跳到编辑器位置, 或将编辑器定位到 Player 当前进度。
- Player 的退出按钮返回本地选歌; 编辑器继续独立运行。网络断开会暂停远程预览。

## 跟随编辑器进度

Editor 顶栏“游玩 → Player 跟随编辑器进度与播放”开启后:

- Player 立即对齐 Editor 当前游标, 随时间轴定位、播放、暂停和播放倍速一起变化。
- 第 0 小节的负时间也会同步, 不会提前跳到第 1 小节或触发开头 Note。
- 从当前位置或从头游玩/自动预览时, Editor 与 Player 一起从所选位置开始播放。
- 谱面准备期间保留最新播放状态, 准备完成后按当前进度对齐, 不回到传输前的位置。
- 停留在 Player 设置页时仍可跟随播放, 判定与音频正常推进; 谱面载入完成不会关闭正在使用的设置页。
- 进度使用独立的小消息, 拖动时间轴不会重新传送整张谱面或音频; 正常播放只低频校时。
- 关闭后 Player 留在当前位置, 恢复独立控制, 不改变自动同步谱面修改的设置。

开关默认关闭, 保存到 Editor 的 `note_params.json`, 重启后保留。
即使关闭了“自动同步编辑到 Player”, 首次开启跟随时仍会先发送当前谱面以建立预览; 后续谱面修改仍需手动发送。
Player 退到后台时优先暂停并停止音频, 返回前台不会被进度同步自动恢复; 可在前台点击继续, 或在 Editor 暂停后重新播放。

## 地址与排障

TCP 监听端口为 `47653`, UDP 发现端口为 `47654`。局域网或系统防火墙需允许相应通信。
自动搜索使用 IPv4 广播; 访客 Wi-Fi、AP 隔离、VPN 或防火墙可能阻止发现。
此时可在 Editor 的“手动输入 Player 地址”填 Player 显示的 `IP:端口` 并输入六位配对码。
同机连接可使用 `127.0.0.1:47653`, 只需一端开启监听。
多网卡电脑显示的二维码地址若无法访问, 优先让 Editor 搜索 Player 或手动输入可达地址。

连接协议有版本检查、配对与数据长度限制, 不加密传输, 用于可信局域网。当前不提供公网穿透。
设备记录位于应用缓存目录中的 `preview-link-Editor.json` / `preview-link-Player.json`。
