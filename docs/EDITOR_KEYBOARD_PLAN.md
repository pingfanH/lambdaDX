# Editor 纯键盘操作方案

日期: 2026-10-14
状态: 设计提案, 部分已实现并接入编辑器。本文保留完整目标, 不等同于已实现功能清单。
当前操作流程与限制见 [EDITOR_KEYBOARD.md](EDITOR_KEYBOARD.md)。F1 现用于设置, 快捷键帮助为 F12 / ?。
范围: 谱面编辑、预览播放、属性、设置与文件操作; 不要求移动鼠标或模拟鼠标点击。

## 1. 设计原则

- 保留现有 G/S/R、Shift+D、Shift+R 的操作习惯, 但所有操作都提供键盘锚点和确认方式。
- 编辑光标、note 选择、播放时钟、UI 焦点分别保存, 不互相隐式替代。
- 方向键始终归当前操作模式所有, 不因为选择为空而突然变成 seek 或播放速度调整。
- 放置、变换和属性修改都有预览、确认、取消; 一次确认对应一次撤销。
- 键盘和鼠标复用吸附、命中、变换、合法性检查及 core 更新逻辑。
- 每个按键事件最多执行一个命令; 打字和中文输入法组合期间不执行画布快捷键。

本文的 Primary 表示 macOS 的 Command、Windows/Linux 的 Ctrl。Alt 表示 macOS 的 Option。
功能键提供可重绑定入口, 兼容需要 Fn 的键盘及系统占用的按键。

## 3. 编辑光标与网格

新增 `EditCursor`: 小节位置、lane/Touch 区域、当前位置候选 note、范围选择锚点。
光标初始位置为当前预览时间对应的小节位置, 后续播放不自动带动光标。
空闲画布导航同步播放时钟, 保留播放/暂停状态; 光标在屏幕内移动时视图不动, 超出可见边界才滚动。后续自然播放不反向移动编辑光标或已分离的视图。
放置草稿与变换中的方向键只调整当前事务。编辑光标可超过歌曲末尾继续编辑, 播放器仍受可播放范围限制。

### 3.1 方向定义

沿用当前可见坐标轴, 而非固定按键对应时间:

| 布局 | 时间提前 / 推后 | 前一 / 后一 lane |
| --- | --- | --- |
| 竖向 | Down / Up | Left / Right |
| 横向 | Left / Right | Up / Down |

下文用「时间方向键」和「lane 方向键」指代这两组。lane 在 1..8 循环。
切换布局不改变光标的小节位置和区域, 只改变方向键映射。

### 3.2 步长与定位

| 按键, 画布空闲时 | 行为 |
| --- | --- |
| 方向键 / Primary+方向键 | 光标移动一格或一个 lane, 同步播放, 仅越界时滚动视图, 不修改已选 note |
| Shift+方向键 / Primary+Shift+方向键 | 时间方向移动一个小节, lane 方向移动四个 lane |
| 1..8 | 光标跳到指定 lane; Touch 模式下使用当前区域环 |
| Home / End | 光标及预览跳到可编辑起点 / 谱面末尾 |
| PageUp / PageDown | 沿时间轴向前 / 向后移动一个可见页面 |
| J | 打开定位框, 输入小节+分数位置或显式秒数, 同步编辑光标、播放时钟和时间轴视图 |
| F8 | 切换吸附 |
| [ / ] | 切换上一 / 下一网格细分 |
| F3, 搜索「细分」 | 直接输入细分数, 包括三连音细分 |

细分 N 表示每小节 N 格, 一格为 `1/N` 小节, 不是 `1/N` 秒。
建议预设 4、8、12、16、24、32、48、64; 默认延续项目设置。
显示网格和放置/手柄吸附必须使用同一份细分。
吸附关闭时方向键仍按当前细分移动, 保留原位置的非网格偏移; 精确位置可通过 J 输入。
秒数与小节互转必须经过谱面 BPM 表, 不用全局 BPM 近似跨 BPM 变更。
位置以项目小节起点为下界; Hold 长度可以为 0, Slide 长度按形状和数据约束校验。
支持长按连续导航; 同时按住两个轴的方向键持续斜向移动, 相反方向抵消。

### 3.3 Touch 区域

Touch/TouchHold 工具下, F4 工具菜单附带区域选择: A、B、C、D、E。
非中心环按 1..8 指定编号, lane 方向键循环编号; C 为单一区域。
区域切换不借用普通字母, 避免和工具、属性、slide 形状冲突。
旋转时编号环绕, C 保持不动; 不把 Touch 编号误当普通 lane。

## 4. 模式与事件优先级

事件路由: 系统/输入法 -> 模态对话框或输入框 -> 放置/变换事务 -> Slide 编辑 -> 当前 UI 焦点 -> 空闲画布。
高优先级处理后消费事件, 不再传给工具栏或播放器。

| 模式 | Enter | Escape | 方向键 |
| --- | --- | --- | --- |
| 空闲画布 | 当前工具放置; 选择工具选中候选 | 先清选择, 再返回选择工具 | 移动光标 |
| Hold 放置 | 确认尾端并完成 | 取消整个待放置 Hold | 调整尾端时间 |
| Star 放置 | 确认当前阶段 | 返回上一步; 头阶段取消全部 | 调整当前阶段 |
| G/S/R | 提交一次变换 | 还原事务前状态 | 更新变换预览 |
| Slide 编辑 | 确认待编辑段; 无待编辑段则结束事务 | 取消待编辑段; 再次按下退出编辑 | 移动段端点光标 |
| 对话框/属性输入 | 激活按钮或提交字段 | 取消并恢复原焦点 | 按控件类型处理 |

未完成事务时不允许保存、切工具、重复、删除或播放启动; 给出非阻塞状态反馈。
F12 / ? 仍能打开帮助, 关闭后回到原事务。已播放的预览可以继续运行, 编辑光标不随播放移动。
鼠标活动不接管已启动的键盘事务; 显式鼠标点击才允许切换输入来源, 且仍由事务消费。

## 5. 选择与重叠 note

| 按键, 空闲画布 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 下一 / 上一个候选 note, 同步预览, 目标越界时滚动视图, 不自动选中; 支持长按 |
| F2 | 仅选择当前候选, 与当前放置工具无关 |
| Shift+F2 | 将候选加入选择或从选择中移除 |
| Primary+A / Primary+Shift+A | 全选 / 清空选择 |
| Primary+Enter | 记录范围锚点; Enter 或再次按下替换为范围内选择 |
| Primary+Shift+Enter / 范围中 Shift+Enter | 开始追加范围 / 确认并将范围追加到选择 |
| Delete / Backspace | 键盘光标模式删除指向的候选; 空白不删除, 鼠标模式删除选择 |
| Primary+Delete / Primary+Backspace | 删除整个选择集合, 与光标指向无关 |

候选优先使用与鼠标一致的 note 头部尺寸与最近中心规则。
同位置重叠时 Tab 可逐个访问; 同头 star 在普通选择中仍是一个 note, 子 slide 在 E 模式内访问。
Tab 始终沿整张谱面遍历, 排序为小节位置、区域、稳定 ID; ID 只用于同位置平局。光标位于 note 之间时从当前位置寻找下一/上一条, 到头后循环, 不局限于当前位置的重叠 note。
候选描边与选择蓝框区分, 蓝框不扩大实际 note 尺寸。
键盘光标指向 note 即更新右侧属性和 F5 的目标, 不要求选择, 也不改变现有选择集合。
范围选择以两次光标位置构成的时间/lane 矩形计算, 复用现有框选相交规则。
Touch 使用其时间轴显示区域坐标; 跨区域的精确多选使用 Shift+F2。
范围预览中方向键、lane 数字键和 Tab 调整另一角, 支持跨屏和越界滚动。Enter 确认范围且不放置 note, Escape 只取消范围并保留之前的选择。范围拥有输入, 不被鼠标接管, 不切换工具或启动播放。Shift+方向键仍为高速移动。

## 6. 工具与放置

F4 打开工具菜单, 方向键选择、Enter 确认; 保留 note 选择, 回到画布。
菜单覆盖 Select、Tap、Hold、Touch、TouchHold、Star/Slide、Break、Eraser。
空闲画布保留 V/T/H/C/K; G/S 在有选择时优先变换、无选择时沿用工具入口。
E 在选中单个 star 时进入 Slide 编辑, 其他情况可沿用 Eraser; F4 是无歧义入口。
工具选择绝不清空框选结果。Break/Eraser 工具的 Enter 作用于候选, 不作用于整组选择; 批量修改使用属性命令。

### 6.1 Tap 与 Touch

选择工具 -> 光标定位 -> Enter 放置。光标停在当前位置, 不自动进一格。
预放置虚影跟随编辑光标, 开启吸附时落在网格上, 只在画布焦点且可放置时显示。
每次放置独立撤销; 同位置已有 note 时允许叠放, 不偷偷改成选择。

### 6.2 Hold 与 TouchHold

1. Enter 固定头部, 初始持续时间为 0。
2. 时间方向键调整尾端; Shift 一次调整一个小节; J 输入尾端位置。
3. Enter 确认, Escape 取消整个待放置 note。

尾端不能早于头部; 零长度允许确认。lane/区域在尾端阶段锁定。
时间轴和 pad 共用长度与锚点语义: 零长度仍显示自然贴图长度, 不用贴图边界充当判定点。
第二次 Enter 不再放置另一个 note; 事务结束后等待按键释放才接受下一次放置。

### 6.3 Star 与 Slide

1. Enter 固定星星头, 显示到启动拍的虚线。
2. 时间方向键设置启动拍; Enter 固定启动拍, 才显示轨迹部分。
3. 形状键和 1..8 指定末端, 时间方向键设置末端时间; Enter 确认段。
4. Shift+Enter 确认段并继续接下一段; 最后一段 Enter 完成整条轨迹。

未选形状时默认直线, 但必须通过合法性检查; 无效段保持预览, 不自动换成其他形状。
Escape 逐级返回, 返回头阶段再取消全部。整个新 Star 含连接轨迹只产生一个历史项。
只有星星头、不带 slide 的放置通过 F3 的「放置星星头」命令完成。

## 7. Slide、同头轨迹与手柄

选中单个 star 后 E 进入 Slide 编辑, 焦点固定在活动子 slide。

| 按键, Slide 编辑内 | 行为 |
| --- | --- |
| Tab / Shift+Tab | 切换下一 / 上一个同头子 slide |
| Primary+Shift+D | 新建同头 slide, 进入启动拍与轨迹放置阶段 |
| Primary+Left / Right | 切换上一 / 下一连接段 |
| Q / Shift+Q | Q / QQ 形状 |
| P / Shift+P | P / PP 形状, 不触发 autoplay |
| V / W | VShape / Wifi, 不切工具 |
| - / , / . / ; | 直线 / 左弧 / 右弧 / Caret |
| S / Z | S / Z 形状, 不触发时间缩放或撤销 |
| 1..8 | 给待编辑形状指定末端 lane; 无待选形状时追加路径点 |
| Backspace | 删除当前轨迹最后路径点, 不删除星星头 |
| Delete | 确认后删除活动子 slide, 保留星星头与其他子 slide |
| F7 | 打开当前段的手柄菜单: 启动拍、末端时间、末端 lane |
| Escape | 取消未确认段或退出 Slide 编辑, 保留星星头选择 |

连接段编辑指向实际段索引, 不因最后段数量不同改写前段形状。
新建同头 slide 保留原头部时间和 lane, 新轨迹可以单独调启动拍、时长及路径。
活动子 slide 单独高亮, 其余轨迹弱化; pad 公共段使用同一几何生成方式。
编辑新连接段用 Shift+Enter 继续, Enter 完成, 与新放置阶段一致。
活动已有段的临时形状/端点修改在 Enter 前只预览, 取消不改变原数据。

普通选择下 F7 也可访问 Hold 尾端、Star 启动拍和 Slide 末端。
手柄菜单 Enter 后进入事务: 时间方向键调时间, lane 方向键只调适用的末端 lane。
Slide 末尾手柄始终位于结束点 lane; 编辑启动拍不得移动星星头。
零高 Hold 和零延时 Star 的手柄仍可从菜单访问, 不依赖鼠标命中。

## 8. G/S/R 与复制重复

### 8.1 变换

| 模式 | 方向键 | 数值输入 |
| --- | --- | --- |
| G 移动 | 时间方向键 +/- 一格; lane 方向键 +/- 一 lane | F3 内的变换参数框输入时间差、lane 差 |
| S 时间缩放 | 时间方向键每次 +/- 0.1 倍; lane 键不操作 | 直接输入正倍率, 如 2 或 0.5 |
| R 旋转 | lane 方向键每次 +/- 一 lane; 时间键不操作 | 直接输入有符号 lane 差, 如 -2 |

S 只修改时间坐标、Hold 时长、Slide 延时和时长, 不改 lane 或头部贴图大小。
S 沿用选择中最早/最晚头部时间的中点作为枢轴; 单 note 头部不动, 长度随倍率变化。
R 以一个 lane 为 45 度; Touch 环编号和 Slide 所有端点同步旋转, 中心 C 不动。
G 不靠鼠标锚点; 操作开始时保存光标和选择原件, 保留组内相对位置。
数字输入期间数字不切 lane, Backspace 编辑数字, Enter 提交变换, Escape 取消变换。
变换始终从原件加累计参数计算, 避免重复吸附造成漂移。
非法倍率、超界时间或无法旋转的形状不提交, 也不部分移动选择。

### 8.2 Shift+D

复制选择并直接进入 G, 新副本使用新 ID, 原件不动。
方向键调整副本, Enter 完成, Escape 取消移动但保留原地副本并选中副本, 延续 Blender 式习惯。
需要取消复制本身时用撤销; 无论确认还是取消移动, 复制都只有一个撤销项。
复制期间只显示副本预览, 不显示当前放置工具虚影。确认事件不得同时触发 Tap/Hold/Star 放置。
复制后移动的时间/lane 差可作为 Shift+R 的重复参数。

### 8.3 Shift+R

重复最后一次已确认且可重复的编辑操作, 不是重做历史。撤销后的重做仍使用 Primary+Shift+Z。
支持 G/S/R、复制+移动以及有明确规律的 note 放置; 保存、选择、seek、删除不进入重复槽。
取消的预览不覆盖上次重复操作; 当前选择不兼容时提示原因且不改谱面。

放置规律使用最近两次独立确认且兼容的有效放置:

- 类型、Break/Ex 等可编辑属性一致; Hold 长度一致; Star 轨迹拓扑、相对启动拍与时长一致。
- 以这两次的小节时间差和 lane/Touch 环编号差作为后继增量; 使用规范化数据和数值容差比较兼容性。
- 时间差按小节计算而非秒数; lane 差按模 8 计算, 正负歧义采用确定的最短方向规则。
- 删除仅从参考序列移除被删除 note, 再以剩余最新两次放置重新计算; 保留更早记录以支持连续删除后的回退。
- 修改既有对象、撤销/重做、粘贴或载入谱面仍打断放置样本序列。
- 未满两次、纯零位移叠放、不同 Touch 环或非法后继位置不生成放置重复操作。

重复生成下一个 note 并延续同一增量, 新 ID、同样吸附、一次撤销; 不进入普通放置虚影事务。
当最近操作是复制+移动时不要求放置样本, 因为增量已被用户明确指定。
绘制层级独立于 ID/插入顺序: 时间较早的 note 在前景, 同时间用稳定次序打破平局。

## 9. 播放与 seek

以下是画布空闲时的编辑器预览键位; 独立 Player 模式可以保留其现有键位。

| 按键 | 行为 |
| --- | --- |
| Space | 播放 / 暂停, 不移动编辑光标 |
| Alt+Enter | seek 到编辑光标, 保留播放/暂停状态 |
| Alt+Left / Right | seek -1 / +1 秒, 与布局无关 |
| Alt+Home | seek 到歌曲播放起点, 不把编辑小节 1 当作秒数 1 |
| Alt+Up / Down | 播放速度 +/- 0.1 |
| O / P | 沿用 autoplay 切换含义, Slide 编辑或输入框内不生效 |
| A | 音乐静音切换 |
| F3, 搜索「从头播放」 | 从播放起点启动播放 |
| F3, 搜索「光标到播放位置」 | 显式把编辑光标移到当前播放时刻 |

所有 seek 走原生 runtime seek, 不重建谱面, 并重置判定/评分及恢复跨时刻长 note、autoplay 显示。
空闲画布的方向键、Home/End、PageUp/PageDown 和 Tab 同步编辑光标与播放时钟, 使用同一原生 seek 入口; 光标仍在可见绘图区内时视图保持不变, 超出边界才滚动。同帧连续导航合并为一次 seek。放置草稿和变换不触发导航 seek。J 确认定位时光标、视图和播放时钟一起限制到实际可播放范围; 普通导航允许编辑光标超过歌曲末尾以继续放置。
模式列表明确区分 noCore、模拟触摸 autoplay、直传 core autoplay 及已有其他模式, 不凭名称推测枚举编号。
详情见 [原生 seek 设计](CORE_NATIVE_SEEK.md)。

## 10. 面板、文件与属性

F6 / Shift+F6 在时间轴、工具栏、属性、播放栏、设置区域之间循环焦点。
面板中 Tab/Shift+Tab 遍历控件, Enter 激活按钮, Space 切换复选项, 方向键操作菜单和数值控件。
因此 Tab 在画布遍历 note、在面板遍历控件, 行为由可见焦点决定。

| 按键 | 行为 |
| --- | --- |
| F3 | 命令搜索, 涵盖所有菜单命令、工具、布局、网格、参数与文件入口 |
| F5 | 打开光标指向的 note 属性, 鼠标模式下使用单个选择; 聚焦首个可编辑字段 |
| F1 / Primary+, | 设置 |
| F12 / ? | 帮助, 关闭恢复原焦点 |
| Primary+S | 保存 |
| Primary+Z / Primary+Shift+Z | 撤销 / 重做; Primary+Y 作为可配置别名 |
| Primary+C / X / V | 复制 / 剪切 / 粘贴, 粘贴锚定编辑光标 |
| B / X / N, 空闲且有选择 | 沿用 Break / Ex / Break+Ex 批量属性切换 |

粘贴保留组内时间差, 以最早头部对齐光标时间, 主 note 区域对齐光标区域。
跨普通 lane/Touch 环的映射不合法时要求通过参数框选择策略, 不静默转换类型。
Each 为只读派生属性, 任何面板和命令都不能手动编辑。
Slide each 仅来自同头轨迹或自动 each 的星星头关系, 不因尾端时间相同就任意标记。
多选属性明确显示混合值, 提交字段只修改该字段; Enter 一次提交, Escape 恢复原值。

文件打开、导出、曲目信息、BPM/Offset、音效和缩放设置均可通过 F3 搜索访问。
文件选择器允许输入路径和键盘遍历, 保存确认框完整支持保存/放弃/取消。
自绘工具按钮必须可聚焦并有可读名称, 不依赖 hover 工具提示。
模态窗口捕获焦点, 关闭恢复先前控件; 不让 Tab 跑到窗口后面的画布。
UI 字号及 note 显示尺寸不随窗口宽高变化而任意缩放, 光标绘制不得影响布局尺寸。

## 11. 完整操作示例

以下示例采用竖向布局、每小节 16 格, 起始光标位于小节 1 的 lane 1。

### 连续 Tap 与规律重复

T -> Enter 放一个 Tap; Up 四次 -> Enter。
两次放置类型与属性一致, 时间差为 1/4 小节、lane 差为 0。
Shift+R 自动生成下一个 Tap, 再按一次继续同样间隔; 光标同步到新头部。
删除若干次放置后, Shift+R 重新使用剩下最新的两个参考; 只剩一个时提示样本不足。

### Hold

H -> 3 -> Enter 固定头部 -> Up 八次 -> Enter 确认 1/2 小节 Hold。
H -> Enter -> Enter 可放置零高 Hold; F2 选择它 -> F7 -> 选尾端 -> Up -> Enter 调长。

### 连接 Slide 与同头轨迹

F4 选择 Star -> 1 -> Enter 固定头部 -> Up 四次 -> Enter 固定启动拍。
- -> 5 -> Up 八次 -> Shift+Enter 确认第一段并继续。
- -> 8 -> Up 四次 -> Enter 完成 `1-5-8`。
F2 选择星星头 -> E -> Primary+Shift+D -> 设置启动拍并 Enter -> 设置另一条轨迹并 Enter。
Tab 切换同头轨迹, F7 调整活动轨迹末端, 其他轨迹不改变。

### 复制、旋转、属性与预览

Tab 定位 note -> F2 选择 -> Shift+D -> Up 四次 -> Enter。
Shift+R 再复制同样偏移 -> R -> 2 -> Enter 旋转两个 lane。
F5 -> Tab 到目标字段 -> 输入并 Enter -> F6 回时间轴。
Space 播放; 空闲画布移动光标同时定位预览, 保留播放状态。Alt+Enter 也可显式定位到编辑光标。

## 12. 实施顺序与验收

### 阶段一: 焦点与光标

新增 EditCursor、统一命令路由与事件消费, 实现 F3/F4/F6、光标导航和键盘候选选择。
先移除空选择方向键对播放的隐式控制; 所有既有冲突按模式规则迁移。

### 阶段二: 放置与变换

为 Hold/Star 放置、G/S/R、复制与手柄增加键盘输入源, 复用现有事务、吸附和历史。
光标/预览状态不进入谱面数据; 提交后的实际修改才进入历史并通知 core 更新。

### 阶段三: Slide 与操作闭环

补齐同头轨迹、连接段、属性与对话框访问, 最后接入重复规律、播放命令和快捷键重绑定。
重绑定需校验同上下文冲突, 允许不同模式复用; 显示所有占用情况, 不偷偷覆盖绑定。

### 必须通过的验收

- 鼠标固定在窗口外, 从载入谱面到 Tap/Touch/Hold/Star 编辑、预览、保存全程完成。
- 横/竖布局与不同 BPM 下移动一格等于显示网格一格, 预览时钟同步; 草稿与变换只修改事务。
- 有无选择时方向键行为一致; 输入文字、数字及中文组合不触发工具/播放/属性切换。
- 同一 Enter 不同时确认 Shift+D 和放置 note; 长按 Enter 不产生重复放置。
- 导航键允许受控长按重复; 放置/删除/确认/Shift+R 只响应独立按下。
- Hold 0 长度可放置、可通过键盘访问尾端; 自然贴图长度与判定锚点一致。
- Star 启动拍阶段只显示虚线; 不合法连接段不提交, 取消可恢复原轨迹。
- 同头多个 slide 均可单独选择、调时长、删除; `1-5` 公共段不因接入 `-8` 改变几何。
- G/S/R 取消完整还原; Shift+D Escape 只取消移动, 撤销一次移除副本。
- 最近两个兼容放置可重复; 不同类型、零位移或非法后继不重复; 删除重算剩余最近两个参考, 明确复制偏移可直接重复。
- 叠放 note 全部可用 Tab 访问, 先放后放不改变按时间定义的前景层级。
- seek 恢复跨时刻 Hold/Slide 与 autoplay, 不重放历史音效或泄漏已结束 note 的评分。
- 所有菜单、设置、帮助、属性和确认框可进入/退出, 焦点可见且关闭后恢复。
- 每次确认修改一次历史、一次 chart revision; core 刷新按 revision 合并, 导航不触发刷新。

验证分三层: 命令路由/事务单元测试、带键盘事件的 egui 集成测试、真实桌面全键盘操作验收。
文档阶段不等于完成上述实现或验证。
