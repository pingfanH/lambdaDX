# Simai 文本编辑

更新: 2026-10-16。

## 入口

- 顶部选择 **Simai** 工作区: 左上文本、左下谱面时间轴、右上 Pad、右下属性。
- 也可以通过分区标题的类型菜单或“视图”菜单加入 Simai 分区。
- 启动时可设置 `MAI2_EDITOR_WORKSPACE=simai`。
- 分区可拖动、拆分、交换和最大化, 每个分区只有一个编辑器。

## 编辑与应用

这里编辑的是当前难度的 Simai 正文, 例如 `(120){4}1,2,3,4,E`,
不是完整的 maidata 文件, 不要包含 `&title=` 或 `&inote_N=` 等字段。
标题、作者和音频偏移仍在原有属性中编辑。

Primary 指 macOS Command, 其他平台 Ctrl。

| 操作 | 行为 |
| --- | --- |
| 输入文本 | 默认在停止输入约 300ms 后后台解析并应用; 可关闭“实时应用文本” |
| Primary+Enter / 标题勾选图标 | 校验并应用到当前谱面, 更新 Pad 与核心 |
| Primary+S / 标题保存图标 | 先应用文本, 再走原有谱面保存流程 |
| Primary+Shift+S / Primary+Shift+E | 应用后另存 / 导出 |
| Primary+O | 打开谱面, 保留未保存确认流程 |
| 标题重新读取图标 | 放弃文本草稿, 从当前谱面重新生成正文 |
| Primary+Z / Primary+Shift+Z | 文本框有焦点时撤销/重做文本编辑 |
| Space | 默认播放/暂停, 不输入空格 |
| Alt+Enter | 跳到文本输入光标对应的拍点, 保留播放/暂停状态 |
| Alt+Shift+Enter | 切换时间轴跟随文本光标, 默认关闭; 开启时立即对齐一次 |

文本框支持行号、选择、复制粘贴和横纵滚动。Enter 换行, Tab 缩进。
默认 Space 播放/暂停, 不输入空格, 其他图形编辑快捷键不侵入文本编辑。点击其他分区后恢复该分区的操作。macOS 的 Alt 为 Option。

## 高亮、跟随与空格

- 默认开启语法高亮: BPM 为暖黄、细分为青色、时长为绿色、Slide 为蓝色、
  修饰符为粉色, `||` 行注释弱化显示。
- 默认开启代码跟随: 输入区以独立红色光标标出当前播放拍点, 播放或拖动时间轴定位到视图外的代码时自动滚动。
  不移动输入光标或改变文本选择; 暂停时手动滚动不会立即被拉回。
- “时间轴跟随文本光标”是独立的反向联动, 默认关闭, Alt+Shift+Enter 切换。开启后移动输入光标到另一拍点会同步播放位置; 光标不动或在同一拍点内部移动时不反复 seek。
  Alt+Enter 无论开关状态都能单次定位。选中文字时以选择的活动端为准; 空白/注释间隙对应下一拍点, 文末对应最后拍点。
  草稿未应用或时间映射还在生成时保留最新定位请求, 等有效映射就绪再执行; 不会用旧文本的字符位置跳转。
- Note 背景默认以蓝色标出 Pad 中所有出现的 note; 可改为仅当前拍点, 或关闭。
- 点击跳转默认使用 Primary+点击代码; 可改为直接点击, 或关闭。空白与注释不触发跳转。
- 尚未应用的草稿暂停播放标记和跟随; 应用后重新建立时间映射。
  映射在后台缓存, 不在播放时逐帧解析。
- 分区标题的跟随图标可切换跟随, 调节图标菜单包含全部文本选项。
  同样的选项位于设置界面的“Simai 文本编辑”。
- 默认开启“空格用于播放/暂停”, Simai 分区中的普通 Space 切换播放, 不输入空格。
  按键与字符事件分帧到达时仍拦截空格, 长按不会反复切换; 粘贴中的空格和输入法选词不受影响, 其他输入框不受影响。
  可手动关闭以恢复输入空格; 换谱面时保留本次运行的设置。
- 从图形谱面生成正文时优先还原常用节拍分数, 避免浮点误差变成连续倍增的细分指令。
  使用绝对拍位校正, 避免长谱面累计误差。

解析错误显示在文本区上方, 谱面保持不变, 草稿不会丢失。
清空谱面请使用正文 `E`, 空白文本不会直接删除所有 note。
一次应用对应一个谱面撤销步; 切回谱面区域可用文档撤销恢复。
实时应用不会抢走输入光标, 也不要求文本分区一直保持可见。
关闭实时应用后使用 Primary+Enter 手动应用; 输入法组合输入期间暂停自动应用。

## 自动保存

- “文件 > 自动保存”和设置中的“编辑与导航 > 自动保存”控制同一开关, 默认关闭。
- 开启后, 已应用的谱面停止修改约 2 秒便保存到当前文件及难度槽位, 保留其他难度与元数据。
- 序列化和临时文件写入在后台完成; 保存完成时再次检查文档与源文件是否变化。
- 未应用或解析失败的文本、未确认的拖动/放置、文件确认弹窗期间不会自动保存。
- 没有源路径时先手动另存; Simai 工程包含模板或 Autoplay 自定义事件时, 先另存为 JSON。
  自动保存不弹出另存对话框, 也不丢弃这些数据。
- 开关在本次运行中保留; 关闭程序仍有未保存内容时保留原有确认流程。

## 循环试听

- 谱面时间轴、Simai 代码和 Autoplay 时间轴共用循环起止点, 启用后以淡黄色背景显示。
  Autoplay 的标尺、紧凑轨道和展开事件轨道均显示范围; 蓝色 note 高亮与红色播放线保留。
- 在底部总览或 Autoplay 标尺 Shift+拖动创建范围; 直接拖动黄色边界调整起点或终点。
  Escape 取消本次调整, 不会意外跳转播放位置。
- “播放”菜单可精确输入起止秒数、启停循环或清除范围。
- 开始播放时, 当前位置在 `[起点, 终点)` 内则继续, 在外则跳到起点; 到达终点后返回起点。
- 暂停时可以定位到循环范围外; 再次播放才回到循环范围内。
- “回到开头”仅在循环已启用且正在播放时回循环起点; 暂停或未循环时回歌曲开头, 不改变播放/暂停状态。

## 同步与保存边界

- 没有文本草稿时, 图形谱面修改会重新生成正文。
- 草稿尚未应用时, 图形修改不会覆盖它; 出现冲突后需先复制保留草稿,
  再重新读取谱面并合并修改, 不允许直接覆盖较新的谱面。
- 切换工作区或关闭文本分区保留草稿; 打开另一谱面/退出时纳入未保存确认。
- 保存、另存、导出都会先校验并应用草稿, 失败时不继续写文件。
- 文本仅修改主谱面的 note、BPM 和速度指令; 模板及实例不展开进正文,
  模板隔离编辑期间停用文本编辑。
- 未改变 note 尽量保留 ID 与 Autoplay 覆盖; 删除或改写 note 会移除其旧覆盖,
  独立 Autoplay 事件和模板元数据保留。包含这些元数据的工程仍需保存为 JSON。
- 应用后暂时保留输入格式; 图形修改、重新读取或重开文件会生成规范正文。
  当前不是保留源文件注释/排版的源码编辑器。

布局需在“视图 > 布局”中显式保存; 原有三套工作区的布局文件仍可读取。
